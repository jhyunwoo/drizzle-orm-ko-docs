Drizzle Kit은 데이터베이스를 introspect하고 마이그레이션이 포함된 schema 파일을 생성하는 CLI 명령을 제공합니다. schema 파일에는 데이터베이스 테이블, 컬럼, 관계, 인덱스에 관한 모든 정보가 포함됩니다.

예를 들어 데이터베이스에 다음과 같은 테이블이 있다고 가정해 보겠습니다.
```sql copy
CREATE TABLE `users_table` (
	`id` integer PRIMARY KEY AUTOINCREMENT NOT NULL,
	`name` text NOT NULL,
	`age` integer NOT NULL,
	`email` text NOT NULL UNIQUE
);
```

데이터베이스 스키마를 가져옵니다.
```bash copy
npx drizzle-kit pull --init
```
introspection 결과로는 `schema.ts` 파일, 데이터베이스 스키마 스냅샷이 들어 있는 `meta` 폴더, 마이그레이션이 담긴 sql 파일, 그리고 [관계형 쿼리](/docs/rqb)를 위한 `relations.ts` 파일이 생성됩니다.

다음은 생성된 `schema.ts` 파일의 예시입니다.
```typescript copy filename="drizzle/schema.ts"
// table schema generated by introspection
import {
  sqliteTable,
  uniqueIndex,
  integer,
  text,
} from "drizzle-orm/sqlite-core";

export const usersTable = sqliteTable(
  "users_table",
  {
    id: integer().primaryKey({ autoIncrement: true }).notNull(),
    name: text().notNull(),
    age: integer().notNull(),
    email: text().notNull(),
  },
  (table) => [
    uniqueIndex("users_table_email_unique").on(table.email)
  ]
);
```
