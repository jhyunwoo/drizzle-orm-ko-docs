| :------------ | :--------------------------------------------------------------------------------------------------------------- |
| `@libsql/client` | 기본값은 `node` 가져오기이며, 번들러에 `target` 또는 `platform`이 설정된 경우 자동으로 `web`로 변경됩니다. `esbuild --platform=browser` |

| `@libsql/client/web` | `next`, `nuxt`, `astro` 등과 같은 풀스택 웹 프레임워크용 모듈 |
| `@libsql/client/http` | `http` 및 `https` 연결 프로토콜용 모듈 |
| `@libsql/client/ws` | `ws` 및 `wss` 연결 프로토콜용 모듈 |
| `@libsql/client/sqlite3` | `:memory:` 및 `file` 연결 프로토콜용 모듈 |
| `@libsql/client-wasm` | WASM을 위한 별도의 실험 패키지 |
