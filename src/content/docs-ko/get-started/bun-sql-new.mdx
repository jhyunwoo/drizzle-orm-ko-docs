# Drizzle과 Bun:SQLite 시작하기

<Prerequisites>  
  - **bun** - JavaScript 올인원 툴킷 - [여기에서 읽어보세요](https://bun.sh/)
  - **Bun SQL** - PostgreSQL 데이터베이스 작업을 위한 네이티브 바인딩 - [여기에서 읽어보세요](https://bun.sh/docs/api/sql)
</Prerequisites>

<Callout type='error'>
버전 `1.2.0`에서 Bun은 동시 구문 실행에 문제가 있어 여러 쿼리를 동시에 실행하려고 하면 오류가 발생할 수 있습니다.
추적할 수 있도록 [github issue](https://github.com/oven-sh/bun/issues/16774)를 만들었습니다. 이 문제가 수정되면 Bun의 SQL 쪽에서는 더 이상 이런 오류를 만나지 않아야 합니다.
</Callout>
