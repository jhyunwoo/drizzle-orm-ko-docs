# Drizzle과 SQLite 시작하기

<Prerequisites>  
  - **dotenv** - 환경 변수를 관리하기 위한 패키지 - [여기에서 읽기](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하기 위한 패키지 - [여기에서 읽기](https://tsx.is/)
  - **libsql** - 전역 애플리케이션에 적합하도록 낮은 쿼리 지연 시간에 최적화된 SQLite 포크 - [여기에서 읽기](https://docs.turso.tech/libsql)
</Prerequisites>

Drizzle는 `libsql` 및 `better-sqlite3` 드라이버를 사용하는 SQLite 연결을 기본적으로 지원합니다.

이 시작 가이드 예제에서는 `libsql`을 사용합니다. 하지만 SQLite에 연결하는 더 많은 방법을 보고 싶다면
우리의 [SQLite Connection](/docs/get-started-sqlite) 페이지를 확인해 보세요.

<InstallPackages lib='@libsql/client'/>

#### Step 2 - 연결 변수 설정하기

<SetupEnv env_variable='DB_FILE_NAME' />

<Callout type='info' title='중요'>
예를 들어 테스트용으로 프로젝트 루트에 SQLite 데이터베이스 파일을 만들고 싶다면, `LibSQL`에서 요구하는 형식이므로 실제 파일 이름 앞에 `file:`을 붙여야 합니다. 예시는 다음과 같습니다:
```plaintext copy
DB_FILE_NAME=file:local.db
```
자세한 내용은 **[LibSQL 문서](https://docs.turso.tech/sdk/ts/reference#local-development)**에서 확인할 수 있습니다.
</Callout>
