#### 4단계 - 데이터베이스 introspect

Drizzle Kit는 데이터베이스를 introspect하고 마이그레이션이 포함된 schema 파일을 생성하는 CLI 명령을 제공합니다. schema 파일에는 데이터베이스 테이블, 컬럼, 관계, 인덱스에 대한 모든 정보가 들어 있습니다.

예를 들어 데이터베이스에 다음과 같은 테이블이 있다고 가정해 보겠습니다:

```sql copy
CREATE TABLE IF NOT EXISTS "todos" (
  "id" uuid DEFAULT gen_random_uuid(),
  "tenant_id" uuid,
  "title" varchar(256),
  "estimate" varchar(256),
  "embedding" vector(3),
  "complete" boolean
);
```

데이터베이스 스키마를 가져오세요:

```bash copy
npx drizzle-kit pull
```

introspection 결과로는 `schema.ts` 파일, 데이터베이스 스키마 스냅샷이 들어 있는 `meta` 폴더, 마이그레이션이 담긴 sql 파일, 그리고 [relational queries](/docs/rqb)를 위한 `relations.ts` 파일이 생성됩니다.

<Callout title='기본 제공 테이블'>
Nile에는 모든 데이터베이스에 포함되는 몇 가지 built-in 테이블이 있습니다. Nile 데이터베이스를 introspect하면 이러한 built-in 테이블도 함께 포함됩니다.
예를 들어 아래 예시에 보이는 `tenants` 테이블이 그렇습니다. 이를 통해 새로운 tenant를 쉽게 만들고, tenant 목록을 조회하는 등 다양한 작업을 수행할 수 있습니다.
</Callout>

생성된 `schema.ts` 파일의 예시는 다음과 같습니다:

```typescript copy filename="src/db/schema.ts"
// table schema generated by introspection
import { pgTable, uuid, text, timestamp, varchar, vector, boolean } from "drizzle-orm/pg-core"
import { sql } from "drizzle-orm"

export const tenants = pgTable("tenants", {
	id: uuid().default(sql`public.uuid_generate_v7()`).primaryKey().notNull(),
	name: text(),
	created: timestamp({ mode: 'string' }).default(sql`LOCALTIMESTAMP`).notNull(),
	updated: timestamp({ mode: 'string' }).default(sql`LOCALTIMESTAMP`).notNull(),
	deleted: timestamp({ mode: 'string' }),
});

export const todos = pgTable("todos", {
	id: uuid().defaultRandom(),
	tenantId: uuid("tenant_id"),
	title: varchar({ length: 256 }),
	estimate: varchar({ length: 256 }),
	embedding: vector({ dimensions: 3 }),
	complete: boolean(),
});
```

introspection에 대한 자세한 내용은 [문서](/docs/drizzle-kit-pull)에서 확인하세요.

#### 9단계 - 테이블 스키마 업데이트 (선택 사항)

테이블 스키마를 업데이트하고 싶다면 `schema.ts` 파일에서 할 수 있습니다. 예를 들어 `todos` 테이블에 새 컬럼 `deadline`을 추가해 보겠습니다:

```typescript copy filename="src/db/schema.ts" {19}
import { pgTable, uuid, text, timestamp, varchar, vector, boolean } from "drizzle-orm/pg-core"
import { sql } from "drizzle-orm"

export const tenants = pgTable("tenants", {
	id: uuid().default(sql`public.uuid_generate_v7()`).primaryKey().notNull(),
	name: text(),
	created: timestamp({ mode: 'string' }).default(sql`LOCALTIMESTAMP`).notNull(),
	updated: timestamp({ mode: 'string' }).default(sql`LOCALTIMESTAMP`).notNull(),
	deleted: timestamp({ mode: 'string' }),
});

export const todos = pgTable("todos", {
	id: uuid().defaultRandom(),
	tenantId: uuid("tenant_id"),
	title: varchar({ length: 256 }),
	estimate: varchar({ length: 256 }),
	embedding: vector({ dimensions: 3 }),
	complete: boolean(),
  deadline: timestamp({ mode: 'string' })
});
```
