# Drizzle과 PostgreSQL로 시작하기

<Prerequisites>
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽기](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽기](https://tsx.is/)
  - **node-postgres** - PostgreSQL 데이터베이스를 쿼리하는 패키지 - [여기에서 읽기](https://node-postgres.com/)
</Prerequisites>

Drizzle은 `node-postgres`와 `postgres.js` 드라이버를 사용하는 PostgreSQL 연결을 기본적으로 지원합니다.

이 시작하기 예제에서는 `node-postgres`를 사용합니다. 하지만 PostgreSQL에 연결하는 다른 방법을 더 찾아보고 싶다면
[PostgreSQL 연결](/docs/get-started-postgresql) 페이지를 확인하세요.

<Callout title='팁'>
아직 PostgreSQL 데이터베이스가 없고 테스트용으로 하나 만들고 싶다면, PostgreSQL을 Docker에 설정하는 가이드를 사용할 수 있습니다.

PostgreSQL in Docker 가이드는 [여기](/docs/guides/postgresql-local-setup)에서 볼 수 있습니다. 설정을 마친 뒤 데이터베이스 URL을 생성하고(가이드에 설명되어 있습니다), 다음 단계로 돌아오세요.
</Callout>
