# Drizzle과 TiDB로 시작하기

<Prerequisites>  
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽기](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽기](https://tsx.is/)
  - **TiDB** - PingCAP의 분산 SQL 데이터베이스 - [여기에서 읽기](https://www.pingcap.com/)
  - **serverless-js** - HTTP 외부 연결이 필요한 서버리스 및 엣지 컴퓨트 플랫폼용 패키지 - [여기에서 읽기](https://github.com/tidbcloud/serverless-js)
</Prerequisites>

<Callout title='중요' type='warning'>
이 튜토리얼에서는 `@tidbcloud/serverless` 드라이버를 사용해 **HTTP** 호출을 보냅니다. TCP로 TiDB에 연결해야 한다면 [MySQL 시작하기](/docs/get-started/mysql-new) 페이지를 참고하세요.
</Callout>
