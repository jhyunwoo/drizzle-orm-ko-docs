# 기존 프로젝트에서 Drizzle과 Bun:SQLite 시작하기

<Prerequisites>  
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽어보세요](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽어보세요](https://tsx.is/)
  - **bun** - JavaScript 올인원 툴킷 - [여기에서 읽어보세요](https://bun.sh/)
  - **bun:sqlite** - 고성능 SQLite3 드라이버의 네이티브 구현 - [여기에서 읽어보세요](https://bun.sh/docs/api/sqlite)
</Prerequisites>

<SetupEnv env_variable='DB_FILE_NAME' />

<Callout type='info' title='중요'>
예를 들어 프로젝트 루트에 SQLite 데이터베이스 파일이 있다면 다음 예시를 사용할 수 있습니다:
```plaintext copy
DB_FILE_NAME=mydb.sqlite
```
</Callout>
