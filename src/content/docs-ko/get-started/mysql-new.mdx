# Drizzle과 MySQL 시작하기

<Prerequisites>  
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽어보세요](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽어보세요](https://tsx.is/)
  - **mysql2** - MySQL 데이터베이스를 조회하는 패키지 - [여기에서 읽어보세요](https://github.com/sidorares/node-mysql2)
</Prerequisites>

MySQL 데이터베이스와 함께 Drizzle을 사용하려면 `mysql2` 드라이버를 사용해야 합니다.

**[공식 웹사이트](https://github.com/sidorares/node-mysql2)**에 따르면,
`mysql2`는 성능에 초점을 맞춘 Node.js용 MySQL 클라이언트입니다.

Drizzle ORM은 `drizzle-orm/mysql2` 패키지로 `mysql2`를 기본 지원합니다.

<FileStructure/>

#### 1단계 - **mysql2** 패키지 설치

<InstallPackages lib='mysql2'/>

#### 2단계 - 연결 변수 설정

<SetupEnv env_variable='DATABASE_URL' />

<Callout title='팁'>
아직 MySQL 데이터베이스가 없고 테스트용으로 하나 만들고 싶다면 MySQL을 Docker에 설정하는 가이드를 사용할 수 있습니다.

MySQL in Docker 가이드는 [여기](/docs/guides/mysql-local-setup)에서 확인할 수 있습니다. 설정을 마치고(가이드에 설명된) 데이터베이스 URL을 만든 뒤 다음 단계로 돌아오세요.
</Callout>
