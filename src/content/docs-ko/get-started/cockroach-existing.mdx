# 기존 프로젝트에서 Drizzle과 CockroachDB 시작하기

<Callout type='error'>
이 페이지는 drizzle 버전 `1.0.0-beta.2` 이상에서 사용할 수 있는 개념을 설명합니다.
</Callout>

<br/>

<Prerequisites>
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽어보세요](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽어보세요](https://tsx.is/)
  - **node-postgres** - PostgreSQL 데이터베이스를 조회하는 패키지 - [여기에서 읽어보세요](https://node-postgres.com/)
</Prerequisites>

<FileStructure/>

#### 1단계 - **node-postgres** 패키지 설치
<Npm>
  drizzle-orm@beta pg dotenv
  -D drizzle-kit@beta tsx @types/pg
</Npm>


#### 2단계 - 연결 변수 설정

<SetupEnv env_variable='DATABASE_URL' />

<Callout title='팁'>
아직 PostgreSQL 데이터베이스가 없고 테스트용으로 하나 만들고 싶다면 PostgreSQL을 Docker에 설정하는 가이드를 사용할 수 있습니다.

PostgreSQL in Docker 가이드는 [여기](/docs/guides/postgresql-local-setup)에서 확인할 수 있습니다. 설정을 마치고(가이드에 설명된) 데이터베이스 URL을 만든 뒤 다음 단계로 돌아오세요.
</Callout>
