# Drizzle과 D1 시작하기

<Prerequisites>  
  - **dotenv** - 환경 변수를 관리하기 위한 패키지 - [여기에서 읽기](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하기 위한 패키지 - [여기에서 읽기](https://tsx.is/)
  - **Cloudflare D1** - Workers 및 Pages 프로젝트에서 조회할 수 있는 서버리스 SQL 데이터베이스 - [여기에서 읽기](https://developers.cloudflare.com/d1/)
  - **wrangler** - Cloudflare 개발자 플랫폼용 명령줄 인터페이스 - [여기에서 읽기](https://developers.cloudflare.com/workers/wrangler)
</Prerequisites>

#### Step 2 - wrangler.toml 설정하기

D1 데이터베이스용 `wrangler.toml` 파일이 필요하며, 내용은 다음과 비슷합니다:
```toml
name = "YOUR PROJECT NAME"
main = "src/index.ts"
compatibility_date = "2022-11-07"
node_compat = true

[[ d1_databases ]]
binding = "DB"
database_name = "YOUR DB NAME"
database_id = "YOUR DB ID"
migrations_dir = "drizzle"
```

#### Step 6 - Drizzle config 파일 설정하기

**Drizzle config** - [Drizzle Kit](/docs/kit-overview)에서 사용하는 설정 파일로, 데이터베이스 연결, 마이그레이션 폴더, 스키마 파일에 대한 모든 정보를 담고 있습니다.

프로젝트 루트에 `drizzle.config.ts` 파일을 만들고 다음 내용을 추가합니다:

```typescript copy filename="drizzle.config.ts"
import 'dotenv/config';
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  out: './drizzle',
  schema: './src/db/schema.ts',
  dialect: 'sqlite',
  driver: 'd1-http',
  dbCredentials: {
    accountId: process.env.CLOUDFLARE_ACCOUNT_ID!,
    databaseId: process.env.CLOUDFLARE_DATABASE_ID!,
    token: process.env.CLOUDFLARE_D1_TOKEN!,
  },
});
```
<Callout title='팁'>
CloudFlare에서 env 변수를 가져오는 방법은 [튜토리얼](/docs/guides/d1-http-with-drizzle-kit)에서 확인할 수 있습니다.
</Callout>
