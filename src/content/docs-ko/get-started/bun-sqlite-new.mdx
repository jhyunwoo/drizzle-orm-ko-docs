# Drizzle과 Bun:SQLite 시작하기

<Prerequisites>  
  - **bun** - JavaScript 올인원 툴킷 - [여기에서 읽어보세요](https://bun.sh/)
  - **bun:sqlite** - 고성능 SQLite3 드라이버의 네이티브 구현 - [여기에서 읽어보세요](https://bun.sh/docs/api/sqlite)
</Prerequisites>

<FileStructure />

#### 1단계 - 필요한 패키지 설치
<Npm>
  drizzle-orm
  -D drizzle-kit @types/bun
</Npm>

#### 2단계 - 연결 변수 설정

<SetupEnv env_variable='DB_FILE_NAME' />

<Callout type='info' title='중요'>
예를 들어 테스트용으로 프로젝트 루트에 SQLite 데이터베이스 파일을 만들고 싶다면 다음 예시를 사용할 수 있습니다:
```plaintext copy
DB_FILE_NAME=mydb.sqlite
```
</Callout>

#### 3단계 - 데이터베이스에 Drizzle ORM 연결하기

<ConnectBun/>

#### 4단계 - 테이블 만들기

<CreateTable/>

#### 5단계 - Drizzle config 파일 설정

<SetupConfig dialect='sqlite' env_variable='DB_FILE_NAME'/>

#### 6단계 - 데이터베이스에 변경 사항 적용하기

<ApplyChanges />

#### 7단계 - 데이터베이스에 시드 데이터를 넣고 조회하기

<QueryDatabase dialect='bun-sqlite' env_variable='DB_FILE_NAME'/>

#### 8단계 - index.ts 파일 실행하기

`bun`으로 스크립트를 실행하려면 다음 명령을 사용하세요:
```bash copy
bun src/index.ts
```
