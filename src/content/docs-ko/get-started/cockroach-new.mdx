# Drizzle과 CockroachDB 시작하기

<Callout type='error'>
이 페이지는 drizzle 버전 `1.0.0-beta.2` 이상에서 사용할 수 있는 개념을 설명합니다.
</Callout>

<br/>

<Prerequisites>
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽어보세요](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽어보세요](https://tsx.is/)
  - **node-postgres** - PostgreSQL 데이터베이스를 조회하는 패키지 - [여기에서 읽어보세요](https://node-postgres.com/)
</Prerequisites>

Drizzle은 `node-postgres`와 `postgres.js` 드라이버를 통해 CockroachDB 연결을 기본 지원합니다.

이 시작하기 예제에서는 `node-postgres`를 사용합니다. 하지만 PostgreSQL에 연결하는 더 많은 방법을 찾고 싶다면
저희의 [CockroachDB Connection](/docs/get-started-cockroach) 페이지를 확인하세요.

<Npm>

  -D drizzle-kit@beta tsx @types/pg
</Npm>
