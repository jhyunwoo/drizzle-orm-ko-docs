# Drizzle과 MSSQL 시작하기

<Callout type='error'>
이 페이지는 drizzle 버전 `1.0.0-beta.2` 이상에서 사용할 수 있는 개념을 설명합니다.
</Callout>

<br/>

<Prerequisites>
  - **dotenv** - 환경 변수를 관리하는 패키지 - [여기에서 읽어보세요](https://www.npmjs.com/package/dotenv)
  - **tsx** - TypeScript 파일을 실행하는 패키지 - [여기에서 읽어보세요](https://tsx.is/)
  - **node-mssql** - MSSQL 데이터베이스를 조회하는 패키지 - [여기에서 읽어보세요](https://github.com/tediousjs/node-mssql)
</Prerequisites>

Drizzle은 `node-mssql` 드라이버를 통해 PostgreSQL 연결을 기본 지원합니다.

</Npm>
