# Drizzle 쿼리

<IsSupportedChipGroup chips={{ 'PostgreSQL': true, 'SQLite': true, 'MySQL': true, 'SingleStore': true }} />

Drizzle ORM은 SQL 위에 얇은 타입드 레이어를 얹도록 설계되었습니다.
우리는 TypeScript에서 SQL 데이터베이스를 다루는 최고의 방식을 설계했다고 진심으로 믿고 있으며, 이제 그것을 더 좋게 만들 차례입니다.

관계형 쿼리는 SQL 데이터베이스의 중첩된 관계형 데이터를 조회할 때 훌륭한 개발자 경험을 제공하기 위한 것으로,
여러 번의 join과 복잡한 데이터 매핑을 피할 수 있게 해줍니다.

이 기능은 기존 스키마 정의와 쿼리 빌더를 확장한 것입니다.
필요에 따라 opt-in 해서 사용할 수 있습니다.
최고 수준의 개발자 경험과 성능을 모두 얻을 수 있도록 신경 썼습니다.

## 모드
Drizzle 관계형 쿼리는 항상 데이터베이스에서 실행할 정확히 하나의 SQL 문만 생성하며, 이로 인해 몇 가지 제약이 있습니다.
모든 데이터베이스에서 최고 수준의 지원을 제공하기 위해 **`modes`**를 도입했습니다.

Drizzle 관계형 쿼리는 내부적으로 하위 쿼리에 대한 lateral join을 사용하며, 현재 PlanetScale은 이를 지원하지 않습니다.

일반 **MySQL** 데이터베이스에서 **mysql2** 드라이버를 사용할 때는 `mode: "default"`를 지정해야 합니다.
**PlanetScale**에서 **mysql2** 드라이버를 사용할 때는 `mode: "planetscale"`를 지정해야 합니다.

```ts copy
import * as schema from './schema';
import { drizzle } from "drizzle-orm/mysql2";
import mysql from "mysql2/promise";

const connection = await mysql.createConnection({
  uri: process.env.PLANETSCALE_DATABASE_URL,
});

const db = drizzle({ client: connection, schema, mode: 'planetscale' });
```

## 조회하기
관계형 쿼리는 Drizzle의 기존 **[query builder](/docs/select)**를 확장한 기능입니다.
`drizzle()` 초기화 시점에 스키마 파일에 있는 모든 `tables`와 `relations`를 제공한 다음,
그저 `db._query` API를 사용하면 됩니다.
<Callout type="info" emoji="ℹ️">
	`drizzle`의 import 경로는 사용 중인 **[database driver](/docs/connect-overview)**에 따라 달라집니다.
</Callout>
<CodeTabs items={["index.ts", "schema.ts"]}>
<CodeTab>
```ts
import * as schema from './schema';
import { drizzle } from 'drizzle-orm/...';

const db = drizzle({ schema });

await db._query.users.findMany(...);
```
```ts
// if you have schema in multiple files
import * as schema1 from './schema1';
import * as schema2 from './schema2';
import { drizzle } from 'drizzle-orm/...';

const db = drizzle({ schema: { ...schema1, ...schema2 } });

await db._query.users.findMany(...);
```
</CodeTab>
```typescript copy
	import { type AnyPgColumn, boolean, integer, pgTable, primaryKey, serial, text, timestamp } from 'drizzle-orm/pg-core';

	import { relations } from 'drizzle-orm';

	export const users = pgTable('users', {
		id: serial('id').primaryKey(),
		name: text('name').notNull(),
		verified: boolean('verified').notNull(),
		invitedBy: integer('invited_by').references((): AnyPgColumn => users.id),
	});

	export const usersRelations = relations(users, ({ one, many }) => ({
		invitee: one(users, { fields: [users.invitedBy], references: [users.id] }),
		usersToGroups: many(usersToGroups),
		posts: many(posts),
	}));

	export const groups = pgTable('groups', {
		id: serial('id').primaryKey(),
		name: text('name').notNull(),
		description: text('description'),
	});

	export const groupsRelations = relations(groups, ({ many }) => ({
		usersToGroups: many(usersToGroups),
	}));

	export const usersToGroups = pgTable('users_to_groups', {
		id: serial('id').primaryKey(),
		userId: integer('user_id').notNull().references(() => users.id),
		groupId: integer('group_id').notNull().references(() => groups.id),
	}, (t) => [
		primaryKey({ columns: [t.userId, t.groupId] })
	]);

	export const usersToGroupsRelations = relations(usersToGroups, ({ one }) => ({
		group: one(groups, { fields: [usersToGroups.groupId], references: [groups.id] }),
		user: one(users, { fields: [usersToGroups.userId], references: [users.id] }),
	}));

	export const posts = pgTable('posts', {
		id: serial('id').primaryKey(),
		content: text('content').notNull(),
		authorId: integer('author_id').references(() => users.id),
		createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
	});

	export const postsRelations = relations(posts, ({ one, many }) => ({
		author: one(users, { fields: [posts.authorId], references: [users.id] }),
		comments: many(comments),
	}));

	export const comments = pgTable('comments', {
		id: serial('id').primaryKey(),
		content: text('content').notNull(),
		creator: integer('creator').references(() => users.id),
		postId: integer('post_id').references(() => posts.id),
		createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
	});

	export const commentsRelations = relations(comments, ({ one, many }) => ({
		post: one(posts, { fields: [comments.postId], references: [posts.id] }),
		author: one(users, { fields: [comments.creator], references: [users.id] }),
		likes: many(commentLikes),
	}));

	export const commentLikes = pgTable('comment_likes', {
		id: serial('id').primaryKey(),
		creator: integer('creator').references(() => users.id),
		commentId: integer('comment_id').references(() => comments.id),
		createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
	});

	export const commentLikesRelations = relations(commentLikes, ({ one }) => ({
		comment: one(comments, { fields: [commentLikes.commentId], references: [comments.id] }),
		author: one(users, { fields: [commentLikes.creator], references: [users.id] }),
	}));
```
</CodeTabs>

### 관계 포함하기

`With` 연산자를 사용하면 여러 관련 테이블의 데이터를 조합하고 결과를 올바르게 집계할 수 있습니다.

**댓글이 포함된 모든 게시물 가져오기:**
```typescript copy
const posts = await db._query.posts.findMany({
	with: {
		comments: true,
	},
});
```

**댓글이 포함된 첫 번째 게시물 가져오기:**
```typescript copy
const post = await db._query.posts.findFirst({
	with: {
		comments: true,
	},
});
```

필요한 만큼 중첩된 `with` 구문을 체이닝할 수 있습니다.
중첩된 모든 `with` 쿼리에 대해 Drizzle은 [Core Type API](/docs/goodies#type-api)를 사용해 타입을 추론합니다.

**게시물을 포함한 모든 사용자 가져오기. 각 게시물에는 댓글 목록이 포함되어야 함:**
```typescript copy
const users = await db._query.users.findMany({
	with: {
		posts: {
			with: {
				comments: true,
			},
		},
	},
});
```

### 부분 필드 선택
`columns` 파라미터를 사용하면 데이터베이스에서 가져오고 싶은 컬럼을 포함하거나 제외할 수 있습니다.

<Callout type="info" emoji="ℹ️">
  Drizzle은 쿼리 레벨에서 부분 선택을 수행하므로, 데이터베이스에서 추가 데이터가 전송되지 않습니다.

  **Drizzle은 하나의 SQL 문만 출력한다는 점을 기억하세요.**
</Callout>

**`id`, `content`만 가져오고 `comments`를 포함한 모든 게시물 가져오기:**
```typescript copy
const posts = await db._query.posts.findMany({
	columns: {
		id: true,
		content: true,
	},
	with: {
		comments: true,
	}
});
```

**`content` 없이 모든 게시물 가져오기:**
```typescript copy
const posts = await db._query.posts.findMany({
	columns: {
		content: false,
	},
});
```

<Callout type="info" emoji="ℹ️">
`true`와 `false` 선택 옵션이 함께 존재하면 모든 `false` 옵션은 무시됩니다.
</Callout>

`name` 필드를 포함하고 `id` 필드를 제외하면 `id` 제외는 중복이 됩니다.
어차피 `name`을 제외한 모든 필드가 제외되기 때문입니다.

**같은 쿼리에서 필드 제외와 포함을 함께 사용하기:**
<Section>
```typescript copy
const users = await db._query.users.findMany({
	columns: {
		name: true,
		id: false //ignored
	},
});
```
```ts
// result type
const users: {
	name: string;
};
```
</Section>

**중첩된 관계에서는 컬럼만 포함하기:**
<Section>
```typescript copy
const res = await db._query.users.findMany({
	columns: {},
	with: {
		posts: true
	}
});
```
```ts
// result type
const res: {
	posts: {
		id: number,
		text: string
	}
}[];
```
</Section>

### 중첩 부분 필드 선택
**[`partial select`](#partial-select)**와 마찬가지로, 중첩된 관계의 컬럼도 포함하거나 제외할 수 있습니다.
```typescript copy
const posts = await db._query.posts.findMany({
	columns: {
		id: true,
		content: true,
	},
	with: {
		comments: {
			columns: {
				authorId: false
			}
		}
	}
});
```

### 선택 필터
SQL 스타일 쿼리 빌더와 마찬가지로,
관계형 쿼리 API에서도 **[`operators`](/docs/operators)** 목록으로 필터와 조건을 정의할 수 있습니다.

`drizzle-orm`에서 가져와 사용할 수도 있고, 콜백 구문에서 바로 사용할 수도 있습니다.
<Section>
```typescript copy
import { eq } from 'drizzle-orm';

const users = await db._query.users.findMany({
	where: eq(users.id, 1)
})
```
```ts copy
const users = await db._query.users.findMany({
	where: (users, { eq }) => eq(users.id, 1),
})
```
</Section>

`id=1`인 게시물과 특정 날짜 이전에 생성된 댓글 찾기:
```typescript copy
await db._query.posts.findMany({
	where: (posts, { eq }) => (eq(posts.id, 1)),
	with: {
		comments: {
			where: (comments, { lt }) => lt(comments.createdAt, new Date()),
		},
	},
});
```

### Limit & Offset
Drizzle ORM은 쿼리와 중첩 엔티티에 대해 `limit` 및 `offset` API를 제공합니다.

**게시물 5개 찾기:**
```typescript copy
await db._query.posts.findMany({
	limit: 5,
});
```

**게시물을 찾고 댓글은 최대 3개까지 가져오기:**
```typescript copy
await db._query.posts.findMany({
	with: {
		comments: {
			limit: 3,
		},
	},
});
```

<Callout type="warning" emoji="⚠️">
  `offset`은 최상위 쿼리에서만 사용할 수 있습니다.
</Callout>
```typescript 
await db._query.posts.findMany({
	limit: 5,
	offset: 2, // correct ✅
	with: {
		comments: {
			offset: 3, // incorrect ❌
			limit: 3,
		},
	},
});
```

5번째부터 10번째 게시물의 댓글이 포함된 게시물 찾기:
```typescript copy
await db._query.posts.findMany({
	limit: 5,
  offset: 5,
	with: {
		comments: true,
	},
});
```

### Order By
Drizzle은 관계형 쿼리 빌더에서 정렬을 위한 API를 제공합니다.

동일한 **[core API](/docs/select#order-by)**를 사용할 수도 있고,
import 없이 콜백의 `order by` 연산자를 사용할 수도 있습니다.

<Section>
```typescript copy
import { desc, asc } from 'drizzle-orm';

await db._query.posts.findMany({
	orderBy: [asc(posts.id)],
});
```
```typescript copy
await db._query.posts.findMany({
	orderBy: (posts, { asc }) => [asc(posts.id)],
});
```
</Section>

**`asc` + `desc`로 정렬하기:**
```typescript copy
await db._query.posts.findMany({
	orderBy: (posts, { asc }) => [asc(posts.id)],
	with: {
		comments: {
			orderBy: (comments, { desc }) => [desc(comments.id)],
		},
	},
});
```

### 사용자 정의 필드 포함하기
관계형 쿼리 API를 사용하면 사용자 정의 추가 필드를 넣을 수 있습니다.
데이터를 가져온 뒤 추가 함수를 적용해야 할 때 유용합니다.
<Callout type="warning" emoji="⚠️">
	현재 `extras`에서는 집계가 지원되지 않습니다. 이 경우에는 **[`core queries`](/docs/select)**를 사용하세요.
</Callout>

<Section>
```typescript copy {5}
import { sql } from 'drizzle-orm';

await db._query.users.findMany({
	extras: {
		loweredName: sql`lower(${users.name})`.as('lowered_name'),
	},
})
```
```typescript copy {3}
await db._query.users.findMany({
	extras: {
		loweredName: (users, { sql }) => sql`lower(${users.name})`.as('lowered_name'),
	},
})
```
</Section>

`lowerName` 키는 반환된 객체의 모든 필드에 함께 포함됩니다.

<Callout type="warning" emoji="⚠️">
  `.as("<name_for_column>")`를 명시적으로 지정해야 합니다.
</Callout>

모든 사용자와 그 그룹을 가져오되, firstName과 lastName을 이어 붙인 `fullName` 필드도 포함하려면
다음과 같이 Drizzle 관계형 쿼리 빌더를 사용할 수 있습니다.

<Section>
```typescript copy
const res = await db._query.users.findMany({
	extras: {
		fullName: sql<string>`concat(${users.name}, " ", ${users.name})`.as('full_name'),
	},
	with: {
		usersToGroups: {
			with: {
				group: true,
			},
		},
	},
});
```
```ts
// result type
const res: {
	id: number;
	name: string;
	verified: boolean;
	invitedBy: number | null;
	fullName: string;
	usersToGroups: {
			group: {
					id: number;
					name: string;
					description: string | null;
			};
	}[];
}[];

```
</Section>


게시물과 댓글을 모두 가져오면서, 게시물 내용 길이와 각 댓글 내용 길이를 계산하는 추가 필드를 포함하려면:
<Section>
```typescript copy
const res = await db._query.posts.findMany({
	extras: (table, { sql }) => ({
		contentLength: (sql<number>`length(${table.content})`).as('content_length'),
	}),
	with: {
		comments: {
			extras: {
				commentSize: sql<number>`length(${comments.content})`.as('comment_size'),
			},
		},
	},
});
```
```ts
// result type
const res: {
	id: number;
	createdAt: Date;
	content: string;
	authorId: number | null;
	contentLength: number;
	comments: {
			id: number;
			createdAt: Date;
			content: string;
			creator: number | null;
			postId: number | null;
			commentSize: number;
	}[];
};
```
</Section>

### Prepared statements
Prepared statement는 쿼리 성능을 크게 향상시키도록 설계되었습니다. [여기](/docs/perf-queries)를 참고하세요.

이 섹션에서는 Drizzle 관계형 쿼리 빌더를 사용해 placeholder를 정의하고
prepared statement를 실행하는 방법을 배울 수 있습니다.

##### **`where`에서 placeholder 사용**

const prepared = db._query.users.findMany({

		},
	},
}).prepare('query_name');

const usersWithPosts = await prepared.execute({ id: 1 });
