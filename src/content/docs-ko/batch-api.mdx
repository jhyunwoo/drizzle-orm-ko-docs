# Batch API

**LibSQL Batch API 설명**:
_[source](https://docs.turso.tech/sdk/ts/reference#batch-transactions)_

> libSQL client library를 사용하면 batch는 암시적 트랜잭션 안에서 순서대로 실행되는 하나 이상의 SQL statement입니다. 
트랜잭션은 libSQL backend가 제어합니다. 모든 statement가 성공하면 
트랜잭션이 커밋됩니다. statement 중 하나라도 실패하면 전체 트랜잭션이 롤백되고 아무 변경도 적용되지 않습니다.

**D1 Batch API 설명**:
_[source](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)_

> Batching은 여러 SQL statement를 데이터베이스로 보내는 단일 호출 안에 담아 전송합니다. 
이 방식은 D1까지의 네트워크 왕복으로 인한 지연 시간을 줄여 주므로 성능에 매우 큰 영향을 줄 수 있습니다. 
D1은 auto-commit으로 동작합니다. 저희 구현은 목록에 있는 각 statement가 순차적으로, 동시에 실행되지 않고,
실행되고 커밋되도록 보장합니다.
Batch된 statement는 SQL 트랜잭션입니다. 시퀀스 안의 statement 하나가 실패하면 
해당 statement에 대한 오류가 반환되고, 전체 시퀀스가 중단되거나 롤백됩니다.

Drizzle ORM은 `LibSQL`, `Neon`, `D1`에서 SQL statement를 batch로 실행하는 API를 제공합니다:
```ts
const batchResponse: BatchResponse = await db.batch([
	db.insert(usersTable).values({ id: 1, name: 'John' }).returning({ id: usersTable.id }),
	db.update(usersTable).set({ name: 'Dan' }).where(eq(usersTable.id, 1)),
	db.query.usersTable.findMany({}),
	db.select().from(usersTable).where(eq(usersTable.id, 1)),
	db.select({ id: usersTable.id, invitedBy: usersTable.invitedBy }).from(usersTable),
]);
```

