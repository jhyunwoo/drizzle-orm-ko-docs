## 로깅

기본 쿼리 로깅을 활성화하려면 `drizzle` 초기화 함수에 `{ logger: true }`를 전달하면 됩니다.

```typescript copy
import { drizzle } from 'drizzle-orm/...'; // driver specific

const db = drizzle({ logger: true });
```

`DefaultLogger` 인스턴스를 만들고 여기에 사용자 정의 `writer`를 제공하면 로그 출력 위치를 바꿀 수 있습니다.

```typescript copy
import { DefaultLogger, LogWriter } from 'drizzle-orm/logger';
import { drizzle } from 'drizzle-orm/...'; // driver specific

class MyLogWriter implements LogWriter {
  write(message: string) {
    // Write to file, stdout, etc.
  }
}

const logger = new DefaultLogger({ writer: new MyLogWriter() });
const db = drizzle({ logger });
```

사용자 정의 logger를 직접 만들 수도 있습니다.

```typescript copy
import { Logger } from 'drizzle-orm/logger';
import { drizzle } from 'drizzle-orm/...'; // driver specific

class MyLogger implements Logger {
  logQuery(query: string, params: unknown[]): void {
    console.log({ query, params });
  }
}

const db = drizzle({ logger: new MyLogger() });
```


## 멀티 프로젝트 스키마

**Table creator** API를 사용하면 테이블 이름을 사용자 정의할 수 있습니다.  
하나의 데이터베이스 안에 여러 프로젝트의 스키마를 함께 유지해야 할 때 매우 유용합니다.

## SQL 쿼리 출력하기

`db` 인스턴스를 사용하거나 **[`standalone query builder`](#standalone-query-builder)**를 사용해 SQL 쿼리를 출력할 수 있습니다.

```typescript copy
const query = db
  .select({ id: users.id, name: users.name })
  .from(users)
  .groupBy(users.id)
  .toSQL();
// query:
{
  sql: 'select 'id', 'name' from 'users' group by 'users'.'id'',
  params: [],
}
```

## 객체 타입 비교하기 (`instanceof` 대안)

`is()` 함수를 사용하면 어떤 객체가 특정 Drizzle 타입인지 확인할 수 있습니다. Drizzle에서 제공하는 어떤 타입과도 함께 사용할 수 있습니다.

<Callout type="warning" emoji="⭐️">
  항상 `instanceof` 대신 `is()`를 사용해야 합니다.
</Callout>

**몇 가지 예시**
```ts
import { Column, is } from 'drizzle-orm';

if (is(value, Column)) {
  // value's type is narrowed to Column
}
```

### Mock Driver

이 API는 Drizzle 테스트 내부에서 사용했고 외부 개발자에게는 드물게만 권장했던, 정의되지 않은 `drizzle({} as any)` API의 후속입니다.

우리는 정식 API를 만들고 공개하기로 했고, 이제 모든 `drizzle` 드라이버는 `drizzle.mock()`을 제공합니다.

```ts
import { drizzle } from "drizzle-orm/...";

const db = drizzle.mock();
```

필요하다면 타입을 위해 schema를 전달할 수 있습니다.

```ts
import { drizzle } from "drizzle-orm/...";
import * as schema from "./schema"

const db = drizzle.mock({ schema });
```
