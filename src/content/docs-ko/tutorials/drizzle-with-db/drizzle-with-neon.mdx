이 튜토리얼에서는 [Neon Postgres](https://neon.tech/) 데이터베이스와 함께 Drizzle ORM을 사용하는 방법을 보여줍니다. 기존 Neon 계정이 없다면 [여기](https://neon.tech)에서 가입하세요. 

<Prerequisites>  
  - Drizzle ORM과 [Drizzle kit](/docs/kit-overview)이 설치되어 있어야 합니다. 아래 명령을 실행하면 설치할 수 있습니다:
  <Npm>
    drizzle-orm 
    -D drizzle-kit
  </Npm>

  - [Neon serverless driver](https://neon.tech/docs/serverless/serverless-driver)도 설치해야 합니다. 
  <Npm>
    @neondatabase/serverless
  </Npm>
  
  - 환경 변수를 관리하기 위한 `dotenv` 패키지가 설치되어 있어야 합니다. 
  <Npm>
    dotenv
  </Npm>  
</Prerequisites>

## Neon과 Drizzle ORM 설정하기

<Steps>
#### 새 Neon 프로젝트 만들기

[Neon Console](https://console.neon.tech/app/projects)에 로그인하고 Projects 섹션으로 이동하세요. 프로젝트를 선택하거나 `New Project` 버튼을 클릭해 새 프로젝트를 만듭니다. 

Neon 프로젝트에는 바로 사용할 수 있는 `neondb`라는 Postgres 데이터베이스가 함께 제공됩니다. 이 튜토리얼에서는 이를 사용합니다.

#### 연결 문자열 변수 설정

프로젝트 콘솔의 **Connection Details** 섹션으로 이동해 데이터베이스 연결 문자열을 찾습니다. 대략 다음과 같은 형태입니다:

```bash
postgres://username:password@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb
```

Neon 데이터베이스에 연결하는 데 사용할 `DATABASE_URL` 환경 변수를 `.env` 또는 `.env.local` 파일에 추가합니다.

```text copy
DATABASE_URL=NEON_DATABASE_CONNECTION_STRING
```

#### 데이터베이스에 Drizzle ORM 연결

`db.ts` 파일을 만들고 데이터베이스 설정을 구성합니다:

```typescript copy filename="src/db.ts"
import { drizzle } from "drizzle-orm/neon-http";
import { neon } from "@neondatabase/serverless";
import { config } from "dotenv";

config({ path: ".env" }); // or .env.local

const sql = neon(process.env.DATABASE_URL!);
export const db = drizzle({ client: sql });
```

#### 테이블 만들기

`schema.ts` 파일을 만들고 테이블을 선언합니다:

```typescript copy filename="src/schema.ts"
import { integer, pgTable, serial, text, timestamp } from 'drizzle-orm/pg-core';

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull(),
  email: text('email').notNull().unique(),
});

export const postsTable = pgTable('posts_table', {
  id: serial('id').primaryKey(),
  title: text('title').notNull(),
  content: text('content').notNull(),
  userId: integer('user_id')
    .notNull()
    .references(() => usersTable.id, { onDelete: 'cascade' }),
  createdAt: timestamp('created_at').notNull().defaultNow(),
  updatedAt: timestamp('updated_at')
    .notNull()
    .$onUpdate(() => new Date()),
});

export type InsertUser = typeof usersTable.$inferInsert;
export type SelectUser = typeof usersTable.$inferSelect;

export type InsertPost = typeof postsTable.$inferInsert;
export type SelectPost = typeof postsTable.$inferSelect;
```

#### Drizzle config 파일 설정

**Drizzle config**는 [Drizzle Kit](/docs/kit-overview)에서 사용되며 데이터베이스 연결, migration 폴더, 스키마 파일에 대한 모든 정보를 담고 있는 설정 파일입니다.

프로젝트 루트에 `drizzle.config.ts` 파일을 만들고 아래 내용을 추가합니다.

```typescript copy filename="drizzle.config.ts"
import { config } from 'dotenv';
import { defineConfig } from "drizzle-kit";

config({ path: '.env' });

export default defineConfig({
  schema: "./src/schema.ts",
  out: "./migrations",
  dialect: "postgresql",
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});
```

#### 데이터베이스에 변경 사항 적용

`drizzle-kit generate` 명령으로 migration을 생성한 다음 `drizzle-kit migrate` 명령으로 실행할 수 있습니다.

migration 생성:

```bash copy
npx drizzle-kit generate
```

이 migration은 `drizzle.config.ts`에 지정한 대로 `drizzle/migrations` 디렉터리에 저장됩니다. 이 디렉터리에는 데이터베이스 스키마를 업데이트하는 데 필요한 SQL 파일과, migration 단계별 스키마 스냅샷을 저장하는 `meta` 폴더가 포함됩니다.

생성되는 migration 예시는 다음과 같습니다:

```sql
CREATE TABLE IF NOT EXISTS "posts_table" (
	"id" serial PRIMARY KEY NOT NULL,
	"title" text NOT NULL,
	"content" text NOT NULL,
	"user_id" integer NOT NULL,
	"created_at" timestamp DEFAULT now() NOT NULL,
	"updated_at" timestamp NOT NULL
);
--> statement-breakpoint
CREATE TABLE IF NOT EXISTS "users_table" (
	"id" serial PRIMARY KEY NOT NULL,
	"name" text NOT NULL,
	"age" integer NOT NULL,
	"email" text NOT NULL,
	CONSTRAINT "users_table_email_unique" UNIQUE("email")
);
--> statement-breakpoint
DO $$ BEGIN
 ALTER TABLE "posts_table" ADD CONSTRAINT "posts_table_user_id_users_table_id_fk" FOREIGN KEY ("user_id") REFERENCES "public"."users_table"("id") ON DELETE cascade ON UPDATE no action;
EXCEPTION
 WHEN duplicate_object THEN null;
END $$;
```

migration 실행:

```bash copy
npx drizzle-kit migrate
```

대신 [Drizzle kit push command](/docs/kit-overview#prototyping-with-db-push)를 사용해 변경 사항을 데이터베이스에 직접 push할 수도 있습니다:

```bash copy
npx drizzle-kit push
```

<Callout type="warning">Push 명령은 로컬 개발 환경에서 새로운 스키마 설계나 변경 사항을 빠르게 테스트해야 하는 상황에 적합하며, migration 파일을 관리하는 오버헤드 없이 빠르게 반복 작업할 수 있게 해줍니다.</Callout>

</Steps>

### 기본 파일 구조

이것이 프로젝트의 기본 파일 구조입니다. `src/db` 디렉터리에는 `db.ts`의 연결 설정, `schema.ts`의 스키마 정의, 그리고 `migrations` 디렉터리에 저장된 migration을 적용하는 역할을 하는 `migrate.ts` migration 스크립트 등 데이터베이스 관련 파일이 있습니다.

```plaintext
📦 <project root>
 ├ 📂 src
 │  ├ 📜 db.ts
 │  └ 📜 schema.ts
 ├ 📂 migrations
 │  ├ 📂 meta
 │  │  ├ 📜 _journal.json
 │  │  └ 📜 0000_snapshot.json
 │  └ 📜 0000_dry_richard_fisk.sql
 ├ 📜 .env
 ├ 📜 drizzle.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

## 쿼리 예제

예를 들어 `src/queries` 폴더를 만들고 insert, select, update, delete 각각의 작업별로 파일을 분리할 수 있습니다.

#### 데이터 삽입

insert 쿼리에 대한 자세한 내용은 [문서](/docs/insert)를 참고하세요.

```typescript copy filename="src/queries/insert.ts" {4, 8}
import { db } from '../db';
import { InsertPost, InsertUser, postsTable, usersTable } from '../schema';

export async function createUser(data: InsertUser) {
  await db.insert(usersTable).values(data);
}

export async function createPost(data: InsertPost) {
  await db.insert(postsTable).values(data);
}
```

#### 데이터 조회

select 쿼리에 대한 자세한 내용은 [문서](/docs/select)를 참고하세요.

<Callout type='warning'>
`getColumns`는 `drizzle-orm@1.0.0-beta.2`부터 사용할 수 있습니다([여기](/docs/upgrade-v1)에서 자세히 보기).

pre-1 버전(`0.45.1` 같은 버전)을 사용 중이라면 `getTableColumns`를 사용하세요.
</Callout>

```typescript copy filename="src/queries/select.ts" {5, 16, 41}
import { asc, between, count, eq, getColumns, sql } from 'drizzle-orm';
import { db } from '../db';
import { SelectUser, usersTable, postsTable } from '../schema';

export async function getUserById(id: SelectUser['id']): Promise<
  Array<{
    id: number;
    name: string;
    age: number;
    email: string;
  }>
> {
  return db.select().from(usersTable).where(eq(usersTable.id, id));
}

export async function getUsersWithPostsCount(
  page = 1,
  pageSize = 5,
): Promise<
  Array<{
    postsCount: number;
    id: number;
    name: string;
    age: number;
    email: string;
  }>
> {
  return db
    .select({
      ...getColumns(usersTable),
      postsCount: count(postsTable.id),
    })
    .from(usersTable)
    .leftJoin(postsTable, eq(usersTable.id, postsTable.userId))
    .groupBy(usersTable.id)
    .orderBy(asc(usersTable.id))
    .limit(pageSize)
    .offset((page - 1) * pageSize);
}

export async function getPostsForLast24Hours(
  page = 1,
  pageSize = 5,
): Promise<
  Array<{
    id: number;
    title: string;
  }>
> {
  return db
    .select({
      id: postsTable.id,
      title: postsTable.title,
    })
    .from(postsTable)
    .where(between(postsTable.createdAt, sql`now() - interval '1 day'`, sql`now()`))
    .orderBy(asc(postsTable.title), asc(postsTable.id))
    .limit(pageSize)
    .offset((page - 1) * pageSize);
}
```

대신 [relational query syntax](/docs/rqb)를 사용할 수도 있습니다.

#### 데이터 업데이트

update 쿼리에 대한 자세한 내용은 [문서](/docs/update)를 참고하세요.

```typescript copy filename="src/queries/update.ts" {5}
import { eq } from 'drizzle-orm';
import { db } from '../db';
import { SelectPost, postsTable } from '../schema';

export async function updatePost(id: SelectPost['id'], data: Partial<Omit<SelectPost, 'id'>>) {
  await db.update(postsTable).set(data).where(eq(postsTable.id, id));
}
```
