이 튜토리얼에서는 [Xata](https://xata.io)와 함께 Drizzle ORM을 사용하는 방법을 보여줍니다. Xata는 개발자가 더 높은 생산성과 성능으로 데이터베이스를 운영하고 확장할 수 있도록 설계된 PostgreSQL 데이터베이스 플랫폼으로, 즉시 copy-on-write 데이터베이스 브랜치, zero-downtime 스키마 변경, 데이터 익명화, AI 기반 성능 모니터링 기능을 제공합니다.

<Prerequisites>
- Drizzle ORM과 [Drizzle kit](/docs/kit-overview)이 설치되어 있어야 합니다. 아래 명령을 실행하면 설치할 수 있습니다:
<Npm>
drizzle-orm
-D drizzle-kit
</Npm>
- 환경 변수 관리를 위해 `dotenv` 패키지가 설치되어 있어야 합니다. 이 패키지에 대한 자세한 내용은 [여기](https://www.npmjs.com/package/dotenv)에서 확인할 수 있습니다.
<Npm>
  dotenv
</Npm>

- Postgres 데이터베이스에 연결하기 위해 `postgres` 패키지가 설치되어 있어야 합니다. 이 패키지에 대한 자세한 내용은 [여기](https://www.npmjs.com/package/postgres)에서 확인할 수 있습니다.
<Npm>
  postgres
</Npm>

- Xata 계정과 데이터베이스가 준비되어 있어야 합니다. 계정과 데이터베이스를 만드는 방법은 [Xata documentation](https://xata.io/documentation/getting-started)을 참고하세요.
</Prerequisites>

[Xata documentation](https://xata.io/documentation/quickstarts/drizzle)을 확인해 Xata와 Drizzle ORM을 함께 사용하는 방법을 더 알아보세요.

## Xata와 Drizzle ORM 설정하기

<Steps>
#### 새 Xata 데이터베이스 만들기

다음 단계에 따라 새 Xata 데이터베이스를 만들 수 있습니다:

1. [Xata 계정](https://xata.io/)에 가입하거나 로그인합니다
2. 대시보드에서 새 데이터베이스를 만듭니다
3. 리전과 데이터베이스 이름을 선택합니다
4. 데이터베이스는 PostgreSQL endpoint와 함께 생성됩니다

#### 연결 문자열 변수 설정

Xata 대시보드로 이동해 PostgreSQL 연결 문자열을 복사합니다. 이 값은 브랜치 overview 페이지에서 찾을 수 있습니다.

`.env` 또는 `.env.local` 파일에 `DATABASE_URL` 변수를 추가합니다:

```plaintext copy
DATABASE_URL=<YOUR_XATA_DATABASE_URL>
```

연결 문자열 형식은 다음과 같습니다:
```plaintext
postgresql://postgres:<password>@<branch-id>.<region>.xata.tech/<database>?sslmode=require
```

예시:
```plaintext
postgresql://postgres:password@t56hgfp7hd2sjfeiqcn66qpo8s.us-east-1.xata.tech/app?sslmode=require
```

<Callout type="info">
Xata는 branch-based development를 제공하므로 개발, staging, production 환경을 위한 격리된 데이터베이스 브랜치를 만들 수 있습니다.
</Callout>

#### 데이터베이스에 Drizzle ORM 연결

`src/db` 디렉터리에 `index.ts` 파일을 만들고 데이터베이스 설정을 구성합니다:

```typescript copy filename="src/db/index.ts"
import { config } from 'dotenv';
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';

config({ path: '.env' }); // or .env.local

const client = postgres(process.env.DATABASE_URL!);
export const db = drizzle({ client });
```

#### 테이블 만들기

`src/db` 디렉터리에 `schema.ts` 파일을 만들고 테이블을 선언합니다:

```typescript copy filename="src/db/schema.ts"
import { integer, pgTable, serial, text, timestamp } from 'drizzle-orm/pg-core';

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull(),
  email: text('email').notNull().unique(),
});

export const postsTable = pgTable('posts_table', {
  id: serial('id').primaryKey(),
  title: text('title').notNull(),
  content: text('content').notNull(),
  userId: integer('user_id')
    .notNull()
    .references(() => usersTable.id, { onDelete: 'cascade' }),
  createdAt: timestamp('created_at').notNull().defaultNow(),
  updatedAt: timestamp('updated_at')
    .notNull()
    .$onUpdate(() => new Date()),
});

export type InsertUser = typeof usersTable.$inferInsert;
export type SelectUser = typeof usersTable.$inferSelect;

export type InsertPost = typeof postsTable.$inferInsert;
export type SelectPost = typeof postsTable.$inferSelect;
```

#### Drizzle config 파일 설정

**Drizzle config**는 [Drizzle Kit](/docs/kit-overview)에서 사용되며 데이터베이스 연결, migration 폴더, 스키마 파일에 대한 모든 정보를 담고 있는 설정 파일입니다.

프로젝트 루트에 `drizzle.config.ts` 파일을 만들고 아래 내용을 추가합니다:

```typescript copy filename="drizzle.config.ts"
import { config } from 'dotenv';
import { defineConfig } from 'drizzle-kit';

config({ path: '.env' });

export default defineConfig({
  schema: './src/db/schema.ts',
  out: './migrations',
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});
```

#### 데이터베이스에 변경 사항 적용

`drizzle-kit generate` 명령으로 migration을 생성한 다음 `drizzle-kit migrate` 명령으로 실행할 수 있습니다.

migration 생성:

```bash copy
npx drizzle-kit generate
```

이 migration은 `drizzle.config.ts`에 지정한 대로 `migrations` 디렉터리에 저장됩니다. 이 디렉터리에는 데이터베이스 스키마를 업데이트하는 데 필요한 SQL 파일과, migration 단계별 스키마 스냅샷을 저장하는 `meta` 폴더가 포함됩니다.

생성되는 migration 예시는 다음과 같습니다:

```sql
CREATE TABLE IF NOT EXISTS "posts_table" (
	"id" serial PRIMARY KEY NOT NULL,
	"title" text NOT NULL,
	"content" text NOT NULL,
	"user_id" integer NOT NULL,
	"created_at" timestamp DEFAULT now() NOT NULL,
	"updated_at" timestamp NOT NULL
);
--> statement-breakpoint
CREATE TABLE IF NOT EXISTS "users_table" (
	"id" serial PRIMARY KEY NOT NULL,
	"name" text NOT NULL,
	"age" integer NOT NULL,
	"email" text NOT NULL,
	CONSTRAINT "users_table_email_unique" UNIQUE("email")
);
--> statement-breakpoint
DO $$ BEGIN
 ALTER TABLE "posts_table" ADD CONSTRAINT "posts_table_user_id_users_table_id_fk" FOREIGN KEY ("user_id") REFERENCES "users_table"("id") ON DELETE cascade ON UPDATE no action;
EXCEPTION
 WHEN duplicate_object THEN null;
END $$;
```

migration 실행:

```bash copy
npx drizzle-kit migrate
```

[마이그레이션 프로세스](/docs/migrations)에 대해 더 알아보세요.

대신 [Drizzle kit push command](/docs/kit-overview#prototyping-with-db-push)를 사용해 변경 사항을 데이터베이스에 직접 push할 수도 있습니다:

```bash copy
npx drizzle-kit push
```

<Callout type="warning">Push 명령은 로컬 개발 환경에서 새로운 스키마 설계나 변경 사항을 빠르게 테스트해야 하는 상황에 적합하며, migration 파일을 관리하는 오버헤드 없이 빠르게 반복 작업할 수 있게 해줍니다.</Callout>

<Callout type="info">
**Xata Branch-Based Development**: Xata는 서로 다른 환경을 위한 데이터베이스 브랜치를 만들 수 있게 해줍니다. 개발, staging, production 브랜치마다 다른 연결 문자열을 사용할 수 있으므로 production에 배포하기 전에 스키마 변경을 쉽게 테스트할 수 있습니다.
</Callout>
</Steps>

## 쿼리 예제

예를 들어 `src/db/queries` 폴더를 만들고 insert, select, update, delete 각각의 작업별로 파일을 분리할 수 있습니다.

#### 데이터 삽입

insert 쿼리에 대한 자세한 내용은 [문서](/docs/insert)를 참고하세요.

```typescript copy filename="src/db/queries/insert.ts" {4, 8}
import { db } from '../index';
import { InsertPost, InsertUser, postsTable, usersTable } from '../schema';

export async function createUser(data: InsertUser) {
  await db.insert(usersTable).values(data);
}

export async function createPost(data: InsertPost) {
  await db.insert(postsTable).values(data);
}
```

#### 데이터 조회

select 쿼리에 대한 자세한 내용은 [문서](/docs/select)를 참고하세요.

<Callout type='warning'>
`getColumns`는 `drizzle-orm@1.0.0-beta.2`부터 사용할 수 있습니다([여기](/docs/upgrade-v1)에서 자세히 보기).

pre-1 버전(`0.45.1` 같은 버전)을 사용 중이라면 `getTableColumns`를 사용하세요.
</Callout>

```typescript copy filename="src/db/queries/select.ts" {5, 16, 41}
import { asc, between, count, eq, getColumns, sql } from 'drizzle-orm';
import { db } from '../index';
import { SelectUser, postsTable, usersTable } from '../schema';

export async function getUserById(id: SelectUser['id']): Promise<
  Array<{
    id: number;
    name: string;
    age: number;
    email: string;
  }>
> {
  return db.select().from(usersTable).where(eq(usersTable.id, id));
}

export async function getUsersWithPostsCount(
  page = 1,
  pageSize = 5,
): Promise<
  Array<{
    postsCount: number;
    id: number;
    name: string;
    age: number;
    email: string;
  }>
> {
  return db
    .select({
      ...getColumns(usersTable),
      postsCount: count(postsTable.id),
    })
    .from(usersTable)
    .leftJoin(postsTable, eq(usersTable.id, postsTable.userId))
    .groupBy(usersTable.id)
    .orderBy(asc(usersTable.id))
    .limit(pageSize)
    .offset((page - 1) * pageSize);
}

export async function getPostsForLast24Hours(
  page = 1,
  pageSize = 5,
): Promise<
  Array<{
    id: number;
    title: string;
  }>
> {
  return db
    .select({
      id: postsTable.id,
      title: postsTable.title,
    })
    .from(postsTable)
    .where(between(postsTable.createdAt, sql`now() - interval '1 day'`, sql`now()`))
    .orderBy(asc(postsTable.title), asc(postsTable.id))
    .limit(pageSize)
    .offset((page - 1) * pageSize);
}
```

대신 [relational query syntax](/docs/rqb)를 사용할 수도 있습니다.

#### 데이터 업데이트

update 쿼리에 대한 자세한 내용은 [문서](/docs/update)를 참고하세요.

```typescript copy filename="src/db/queries/update.ts" {5}
import { eq } from 'drizzle-orm';
import { db } from '../index';
import { SelectPost, postsTable } from '../schema';

export async function updatePost(id: SelectPost['id'], data: Partial<Omit<SelectPost, 'id'>>) {
  await db.update(postsTable).set(data).where(eq(postsTable.id, id));
}
```

#### 데이터 삭제

delete 쿼리에 대한 자세한 내용은 [문서](/docs/delete)를 참고하세요.

```typescript copy filename="src/db/queries/delete.ts" {5}
import { eq } from 'drizzle-orm';
import { db } from '../index';
import { SelectUser, usersTable } from '../schema';

export async function deleteUser(id: SelectUser['id']) {
  await db.delete(usersTable).where(eq(usersTable.id, id));
}
```
