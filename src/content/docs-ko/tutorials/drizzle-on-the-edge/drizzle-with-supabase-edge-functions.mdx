이 튜토리얼에서는 [Supabase Edge Functions](https://supabase.com/docs/guides/functions)와 함께 Drizzle ORM을 사용하는 방법을 보여줍니다.

<Prerequisites>
- 최신 버전의 [Supabase CLI](https://supabase.com/docs/guides/cli/getting-started#installing-the-supabase-cli)가 설치되어 있어야 합니다.
- Drizzle ORM과 [Drizzle kit](https://orm.drizzle.team/kit-docs/overview)이 설치되어 있어야 합니다. 아래 명령을 실행하면 설치할 수 있습니다:
<Npm>
drizzle-orm
-D drizzle-kit
</Npm>
- Docker Desktop이 설치되어 있어야 합니다. 이는 로컬 개발의 필수 조건입니다. 설치는 공식 [docs](https://docs.docker.com/desktop)를 참고하세요.
</Prerequisites>

로컬 머신에서 기본 Edge Function을 만든 다음 배포하는 방법을 알아보려면 [Edge Functions Quickstart](https://supabase.com/docs/guides/functions/quickstart)를 참고하세요.

<Steps>
#### 테이블 만들기

`src` 디렉터리에 `schema.ts` 파일을 만들고 테이블 스키마를 선언합니다.

```typescript copy filename="src/schema.ts"
import { pgTable, serial, text, integer } from "drizzle-orm/pg-core";

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull()
})
```

이 파일은 데이터베이스용 migration을 생성하는 데 사용됩니다.

#### Drizzle config 파일 설정

**Drizzle config**는 [Drizzle Kit](https://orm.drizzle.team/kit-docs/overview)에서 사용되며 데이터베이스 연결, migration 폴더, 스키마 파일에 대한 모든 정보를 담고 있는 설정 파일입니다.

프로젝트 루트에 `drizzle.config.ts` 파일을 만들고 아래 내용을 추가합니다.

```typescript copy filename="drizzle.config.ts"
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./src/schema.ts",
  out: "./supabase/migrations",
  dialect: "postgresql",
});
```

이 튜토리얼에서는 Drizzle kit를 사용해 스키마에 대한 migration을 생성할 것입니다.

#### 새 Supabase 프로젝트 초기화

로컬 머신의 폴더에서 새 Supabase 프로젝트를 만듭니다.

```bash copy
supabase init
```

이 명령은 `config.toml` 파일이 들어 있는 `supabase` 폴더를 생성합니다:

```text
└── supabase
    └── config.toml
```

Visual Studio Code를 사용 중이라면, Deno 설정을 위해 [Supabase 문서](https://supabase.com/docs/guides/functions/local-development#deno-with-visual-studio-code)을 따라 설정하세요.

#### migration 생성

`drizzle-kit generate` 명령을 실행해 migration을 생성합니다:

```bash copy
npx drizzle-kit generate
```

이 명령은 `supabase/migrations` 디렉터리에 새 migration 파일을 생성합니다.

#### migration 적용

Supabase 로컬 개발 스택을 시작하려면 아래 명령을 실행합니다.

```bash copy
supabase start
```

migration을 적용하려면 아래 명령을 실행합니다.

```bash copy
supabase migration up
```

Supabase migration에 대한 자세한 내용은 [문서](https://supabase.com/docs/guides/deployment/database-migrations)에서 확인할 수 있습니다.

<Callout type="warning">Docker를 실행하는 것을 잊지 마세요</Callout>

대신 `drizzle-kit migrate` 명령으로 migration을 적용할 수도 있습니다. 이 migration 프로세스에 대한 자세한 내용은 [문서](https://orm.drizzle.team/docs/migrations)를 참고하세요.

#### 새 Edge Function 만들기

`supabase functions new [FUNCTION_NAME]` 명령을 실행해 새 Edge Function을 만듭니다:

```bash copy
supabase functions new drizzle-tutorial
```

이 명령은 `supabase/functions` 디렉터리 안에 함수 이름으로 된 새 폴더를 생성합니다:

```text
└── supabase
    └── functions
    │   └── drizzle-tutorial
    │   │   ├── .npmrc ## Function-specific npm configuration (if needed)
    │   │   ├── deno.json ## Function-specific Deno configuration
    │   │   └── index.ts ## Your function code
```

새 Edge Function을 만들면 기본적으로 TypeScript를 사용합니다. 하지만 JavaScript로 Edge Function을 작성하는 것도 가능합니다. 자세한 내용은 [문서](https://supabase.com/docs/guides/functions/quickstart#not-using-typescript)를 참고하세요.

#### import 설정

`supabase/functions/drizzle-tutorial` 디렉터리의 `deno.json` 파일에 아래 import를 추가합니다:

```json copy filename="supabase/functions/drizzle-tutorial/deno.json"
{
  "imports": {
    "drizzle-orm/": "npm:/drizzle-orm/",
    "postgres": "npm:postgres"
  }
}
```

의존성 관리에 대한 자세한 내용은 [여기](https://supabase.com/docs/guides/functions/dependencies#managing-dependencies)를 참고하세요.

#### 스키마를 functions 디렉터리로 복사하기

edge function에서 사용할 코드를 `src/schema.ts` 파일에서 `supabase/functions/drizzle-tutorial/index.ts` 파일로 복사합니다:

```typescript copy filename="supabase/functions/drizzle-tutorial/index.ts"
// Setup type definitions for built-in Supabase Runtime APIs
import "jsr:@supabase/functions-js/edge-runtime.d.ts"
import { pgTable, serial, text, integer } from "drizzle-orm/pg-core";

const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull()
})

Deno.serve(async (req) => {
  const { name } = await req.json()
  const data = {
    message: `Hello ${name}!`,
  }

  return new Response(
    JSON.stringify(data),
    { headers: { "Content-Type": "application/json" } },
  )
})  
```

<Callout type="warning">
Deno 생태계에서는 각 함수를 각자의 의존성과 설정을 가진 독립적인 프로젝트로 취급해야 합니다.
이런 이유로 Supabase는 일부 설정이 중복되더라도 각 함수 디렉터리 안에 별도의 설정 파일(`deno.json`, `.npmrc`, 또는 `import_map.json`)을 유지할 것을 권장합니다. 자세한 내용은 [여기](https://supabase.com/docs/guides/functions/dependencies#managing-dependencies)를 참고하세요.
</Callout>

#### 데이터베이스에 Drizzle ORM 연결

edge function 코드를 데이터베이스 설정으로 업데이트합니다.

```typescript copy filename="supabase/functions/drizzle-tutorial/index.ts" {14,17,18}
// Setup type definitions for built-in Supabase Runtime APIs
import { integer, pgTable, serial, text } from "drizzle-orm/pg-core";
import { drizzle } from "drizzle-orm/postgres-js";
import "jsr:@supabase/functions-js/edge-runtime.d.ts";
import postgres from "postgres";

const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull()
})

Deno.serve(async () => {
  const connectionString = Deno.env.get("SUPABASE_DB_URL")!;

  // Disable prefetch as it is not supported for "Transaction" pool mode
  const client = postgres(connectionString, { prepare: false });
  const db = drizzle({ client });

  await db.insert(usersTable).values({
    name: "Alice",
    age: 25
  })
  const data = await db.select().from(usersTable);

  return new Response(
    JSON.stringify(data)
  )
})
```

`SUPABASE_DB_URL`은 직접 데이터베이스 연결을 위한 기본 환경 변수입니다. Supabase Edge Functions에서 환경 변수를 관리하는 방법에 대한 자세한 내용은 [문서](https://supabase.com/docs/guides/functions/secrets)를 참고하세요.

#### 로컬에서 코드 테스트하기

함수를 로컬에서 테스트하려면 아래 명령을 실행합니다:

```bash copy
supabase functions serve --no-verify-jwt
```

브라우저에서 생성한 경로 `(e.g. /drizzle-tutorial)`로 이동합니다:

```plaintext
[
  {
    "id": 1,
    "name": "Alice",
    "age": 25
  }
]
```

#### 로컬 프로젝트를 호스팅된 Supabase 프로젝트에 연결하기

[대시보드](https://supabase.com/dashboard)에서 새 Supabase 프로젝트를 만들거나 이 [링크](https://database.new/)를 따라가서 만들 수 있습니다.

프로젝트 설정에서 `Reference ID`를 복사한 다음, 아래 명령을 실행해 로컬 개발 프로젝트를 호스팅된 Supabase 프로젝트와 연결합니다:

```bash copy
supabase link --project-ref=<REFERENCE_ID>
```

아래 명령을 실행해 스키마 변경 사항을 호스팅된 Supabase 프로젝트로 push합니다:

```bash copy
supabase db push
```

#### 환경 변수 설정

대시보드 상단 바에서 **Connect**를 클릭하면 `Project connect details`를 찾을 수 있습니다. `Transaction pooler` 섹션에서 URI를 복사하세요. 비밀번호 플레이스홀더를 실제 데이터베이스 비밀번호로 바꾸는 것도 잊지 마세요.

Connection Pooler에 대한 자세한 내용은 [문서](https://supabase.com/docs/guides/database/connecting-to-postgres#connection-pooler)를 참고하세요.

edge function 코드에서 `SUPABASE_DB_URL` 대신 `DATABASE_URL` 환경 변수를 사용하도록 업데이트합니다:

```typescript copy filename="supabase/functions/drizzle-tutorial/index.ts"
// imports

// const connectionString = Deno.env.get("SUPABASE_DB_URL")!;
const connectionString = Deno.env.get("DATABASE_URL")!;

// code
```

환경 변수를 설정하려면 아래 명령을 실행합니다:

```bash copy
supabase secrets set DATABASE_URL=<CONNECTION_STRING>
```

Supabase Edge Functions에서 환경 변수를 관리하는 방법에 대한 자세한 내용은 [문서](https://supabase.com/docs/guides/functions/secrets)를 참고하세요.

#### 함수 배포

아래 명령을 실행해 함수를 배포합니다:

```bash copy
supabase functions deploy drizzle-tutorial --no-verify-jwt
```
</Steps>

마지막으로, 배포된 프로젝트의 URL을 사용하고 만들어 둔 경로 `(e.g. /drizzle-tutorial)`로 이동하여 edge function에 접근할 수 있습니다.
