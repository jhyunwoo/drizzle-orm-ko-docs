이 튜토리얼에서는 [Netlify Edge Functions](https://docs.netlify.com/edge-functions/overview/)와 [Neon Postgres](https://neon.tech/) 데이터베이스와 함께 Drizzle ORM을 사용하는 방법을 보여줍니다.

<Prerequisites>
- 최신 버전의 [Netlify CLI](https://docs.netlify.com/cli/get-started/#installation)가 설치되어 있어야 합니다.
- Drizzle ORM과 [Drizzle kit](/docs/kit-overview)이 설치되어 있어야 합니다. 아래 명령으로 설치할 수 있습니다:
<Npm>
drizzle-orm
-D drizzle-kit
</Npm>

- 환경 변수를 관리하기 위한 `dotenv` 패키지가 설치되어 있어야 합니다. Node.js `v20.6.0` 이상을 사용한다면 `.env` 파일을 네이티브하게 지원하므로 설치할 필요가 없습니다. 자세한 내용은 [여기](https://nodejs.org/en/blog/release/v20.6.0#built-in-env-file-support)를 참고하세요.
<Npm>
  dotenv
</Npm>

- 선택 사항으로, 이후 사용할 `Context` 객체의 타입을 import하기 위해 `@netlify/edge-functions` 패키지를 설치할 수 있습니다.
<Npm>
  @netlify/edge-functions
</Npm>
</Prerequisites>

<Callout type="warning">
여기서 설치하는 패키지들은 [Create a table](#create-a-table), [Setup Drizzle config file](#setup-drizzle-config-file), [Apply changes to the database](#apply-changes-to-the-database) 단계에서 데이터베이스에 테이블을 만들기 위해서만 사용됩니다. 이 패키지들은 Netlify Edge Functions 내부에서 실행되는 코드에는 영향을 주지 않습니다. Edge Functions에서 필요한 패키지는 `import_map.json`을 사용해 import하겠습니다.
</Callout>

<Steps>
#### Neon Postgres 설정

[Neon Console](https://console.neon.tech/app/projects)에 로그인한 뒤 Projects 섹션으로 이동하세요. 기존 프로젝트를 선택하거나 `New Project` 버튼을 눌러 새 프로젝트를 만듭니다.

Neon 프로젝트에는 바로 사용할 수 있는 `neondb`라는 Postgres 데이터베이스가 기본으로 제공됩니다. 이 튜토리얼에서는 이를 사용하겠습니다.

#### 연결 문자열 변수 설정

**Project Dashboard** 섹션에서 `Connect` 버튼을 클릭한 뒤 데이터베이스 연결 문자열을 복사하세요. 대략 다음과 같은 형태입니다:

```bash
postgres://username:password@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb?sslmode=require
```

Neon 데이터베이스에 연결할 때 사용할 `DATABASE_URL` 환경 변수를 `.env` 파일에 추가합니다.

```text copy
DATABASE_URL=NEON_DATABASE_CONNECTION_STRING
```

#### Netlify Edge Functions 설정

프로젝트 루트에 `netlify/edge-functions` 디렉터리를 만듭니다. 이 위치에 Edge Functions를 저장합니다.

`netlify/edge-functions` 디렉터리 안에 `user.ts` 함수를 만듭니다.

```typescript copy filename="netlify/edge-functions/user.ts"
import type { Context } from "@netlify/edge-functions";

export default async (request: Request, context: Context) => {
  return new Response("User data");
};
```

<Callout type="warning">
`Request`와 `Response` 객체의 타입은 전역 스코프에 있습니다.
</Callout>

#### import 설정

프로젝트 루트에 `import_map.json` 파일을 만들고 아래 내용을 추가합니다:

```json copy filename="import_map.json"
{
  "imports": {
    "drizzle-orm/": "https://esm.sh/drizzle-orm/",
    "@neondatabase/serverless": "https://esm.sh/@neondatabase/serverless"
  }
}
```

Netlify Edge Functions에서 `import_map.json`에 대한 자세한 내용은 [여기](https://docs.netlify.com/edge-functions/api/#import-maps)를 참고하세요.

#### Netlify 설정 파일 만들기

프로젝트 루트에 `netlify.toml` 파일을 만들고 아래 내용을 추가합니다:

```toml copy filename="netlify.toml"
[functions]
  deno_import_map = "./import_map.json"

[[edge_functions]]
  path = "/user"
  function = "user"
```

이 설정은 Netlify가 Deno imports에 `import_map.json` 파일을 사용하고, `/user` 경로로 들어오는 요청을 `user.ts` 함수로 라우팅하도록 알려줍니다.  
`netlify.toml`에 대한 자세한 내용은 [여기](https://docs.netlify.com/configure-builds/file-based-configuration/)에서 확인할 수 있습니다.

#### 테이블 만들기

`netlify/edge-functions/common` 디렉터리에 `schema.ts` 파일을 만들고 테이블 스키마를 선언합니다:

```typescript copy filename="netlify/edge-functions/common/schema.ts"
import { pgTable, serial, text, integer } from "drizzle-orm/pg-core";

export const usersTable = pgTable('users_table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  age: integer('age').notNull(),
  email: text('email').notNull().unique(),
})
```

#### Drizzle config 파일 설정

**Drizzle config**는 [Drizzle Kit](/docs/kit-overview)에서 사용하는 설정 파일로, 데이터베이스 연결, 마이그레이션 폴더, 스키마 파일에 대한 모든 정보를 담고 있습니다.

프로젝트 루트에 `drizzle.config.ts` 파일을 만들고 아래 내용을 추가합니다:

```typescript copy filename="drizzle.config.ts"
import 'dotenv/config'; // remove this line if you use Node.js v20.6.0 or later
import type { Config } from "drizzle-kit";

export default {
  schema: './netlify/edge-functions/common/schema.ts',
  out: './drizzle',
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
} satisfies Config;
```

이 튜토리얼에서는 Drizzle kit를 사용해 Neon 데이터베이스에 변경 사항을 push 하겠습니다.

#### 데이터베이스에 변경 사항 적용

```bash copy
npx drizzle-kit push
```
<Callout type="warning">Push 명령은 로컬 개발 환경에서 새로운 스키마 설계나 변경 사항을 빠르게 시험해 보고 싶을 때 적합하며, 마이그레이션 파일을 관리하는 오버헤드 없이 빠르게 반복 작업할 수 있게 해 줍니다.</Callout>

대신 migrations 워크플로를 사용할 수도 있습니다. 자세한 내용은 [Migrations](/docs/migrations)를 참고하세요.

#### 데이터베이스에 Drizzle ORM 연결

`netlify/edge-functions/user.ts` 파일을 업데이트하고 데이터베이스 설정을 구성합니다:

```typescript copy filename="netlify/edge-functions/user.ts"
import type { Context } from "@netlify/edge-functions";
import { usersTable } from "./common/schema.ts";
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';

export default async (request: Request, context: Context) => {
  const sql = neon(Netlify.env.get("DATABASE_URL")!);
  const db = drizzle({ client: sql });

  const users = await db.select().from(usersTable);

  return new Response(JSON.stringify(users));
};
```

<Callout type="warning">
VS Code를 사용 중이라면 imports 아래에 빨간 밑줄이 보일 수 있습니다. 그래도 Edge Function은 정상 실행됩니다. 빨간 밑줄을 없애려면 다음 단계에서 VS Code가 Edge Functions를 사용하도록 설정할 수 있습니다.
</Callout>

#### 로컬에서 코드 테스트하기

Netlify dev 서버를 시작하려면 아래 명령을 실행하세요:

```bash copy
netlify dev
```

명령을 처음 실행하면 VS Code가 Edge Functions를 사용하도록 설정할지 제안합니다. 설정하려면 `Yes`를 클릭하세요. `.vscode` 디렉터리 안에 `settings.json` 파일이 생성됩니다.  
그래도 빨간 밑줄이 남아 있다면 Deno Language Server를 재시작하면 됩니다.

브라우저를 열고 `/user` 경로로 이동하세요. Neon 데이터베이스에서 반환된 사용자 데이터를 볼 수 있습니다:

```plaintext
[]
```

`users_table` 테이블에 아직 데이터를 넣지 않았다면 빈 배열이 나올 수 있습니다.

#### 새 Netlify 프로젝트 초기화

아래 명령으로 새 Netlify 프로젝트를 초기화합니다:

```bash copy
netlify init
```

CLI 질문에 답하면서 새 Netlify 프로젝트를 만드세요. 이 튜토리얼에서는 `Yes, create and deploy site manually` -> `<YOUR_TEAM>` -> `<SITE_NAME>`를 선택합니다.

#### Netlify 환경 변수 설정

아래 명령으로 환경 변수를 Netlify로 가져옵니다:

```bash copy
netlify env:import .env
```

Netlify 환경 변수에 대한 자세한 내용은 [여기](https://docs.netlify.com/environment-variables/get-started/)를 참고하세요.

#### 프로젝트 배포

프로젝트를 배포하려면 아래 명령을 실행합니다:

```bash copy
netlify deploy
```

CLI 안내에 따라 프로젝트를 Netlify에 배포하세요. 이 튜토리얼에서 publish directory는 `'.'`입니다.

기본적으로는 [draft deployment](https://docs.netlify.com/cli/get-started/#draft-deploys)입니다.  
프로덕션 배포를 하려면 아래 명령을 실행하세요:

```bash copy
netlify deploy --prod
```

</Steps>

마지막으로, 배포된 웹사이트 URL로 이동한 뒤 여러분이 만든 경로 `(예: /user)`에 접속하면 edge function에 접근할 수 있습니다.
