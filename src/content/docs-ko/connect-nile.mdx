# Drizzle \<\> Nile

<Prerequisites>
- Drizzle과 데이터베이스 [연결 기본](/docs/connect-overview)
- Nile Database - [웹사이트](https://thenile.dev)
- Drizzle PostgreSQL drivers - [문서](/docs/get-started-postgresql)
</Prerequisites>

**[공식 웹사이트](https://thenile.dev)**에 따르면, Nile은 멀티테넌트 앱을 위해 다시 설계된 PostgreSQL입니다.

공식 **[Nile + Drizzle Quickstart](https://www.thenile.dev/docs/getting-started/languages/drizzle)** 및 **[Migration](https://www.thenile.dev/docs/getting-started/schema_migrations/drizzle)** 문서를 확인하세요.

Nile은 Drizzle의 어떤 Postgres 드라이버와도 함께 사용할 수 있으며, 여기서는 아래에서 `node-postgres` 사용법을 보여드리겠습니다.

#### 1단계 - 패키지 설치

<Npm>
drizzle-orm postgres
-D drizzle-kit
</Npm>

#### 2단계 - 드라이버 초기화 및 쿼리 실행

```typescript copy filename="index.ts"
// Make sure to install the 'pg' package
import { drizzle } from 'drizzle-orm/node-postgres'

const db = drizzle(process.env.NILEDB_URL);

const response = await db.select().from(...);
```

기존 드라이버를 직접 제공해야 하는 경우:

```typescript copy filename="index.ts"
// Make sure to install the 'pg' package
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";
const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});
const db = drizzle({ client: pool });

const response = await db.select().from(...);
```

#### 가상 테넌트 데이터베이스에 연결하기

Nile은 가상 테넌트 데이터베이스를 제공합니다. 테넌트 컨텍스트를 설정하면 Nile은 해당 특정 테넌트의 가상 데이터베이스로 쿼리를 전달하며, 모든 쿼리는 그 테넌트에 적용됩니다. (즉, `select * from table`은 해당 테넌트의 레코드만 반환합니다.) 

테넌트 컨텍스트를 설정하기 위해, 각 쿼리를 실행하기 전에 적절한 테넌트 컨텍스트를 설정하는 트랜잭션 안에서 각 쿼리를 감쌉니다.

테넌트 ID는 단순히 래퍼에 인자로 전달하면 됩니다:

```typescript copy filename="index.ts"
import { drizzle } from 'drizzle-orm/node-postgres';
import { todosTable, tenants } from "./db/schema";
import { sql } from 'drizzle-orm';
import 'dotenv/config';

const db = drizzle(process.env.NILEDB_URL);

function tenantDB<T>(tenantId: string, cb: (tx: any) => T | Promise<T>): Promise<T> {
  return db.transaction(async (tx) => {
    if (tenantId) {
      await tx.execute(sql`set local nile.tenant_id = '${sql.raw(tenantId)}'`);
    }

    return cb(tx);
  }) as Promise<T>;
}

// In a webapp, you'll likely get it from the request path parameters or headers
const tenantId = '01943e56-16df-754f-a7b6-6234c368b400'

const response = await tenantDB(tenantId, async (tx) => {
    // No need for a "where" clause here
    return await tx.select().from(todosTable);
});

console.log(response);
```

이를 지원하는 웹 프레임워크를 사용하고 있다면 [AsyncLocalStorage](https://nodejs.org/api/async_context.html)를 설정하고, 미들웨어를 사용해 여기에 테넌트 ID를 채울 수 있습니다. 이 경우 Drizzle 클라이언트 설정은 다음과 같습니다:

```typescript copy filename="db/index.ts
import { drizzle } from 'drizzle-orm/node-postgres';
import dotenv from "dotenv/config";
import { sql } from "drizzle-orm";
import { AsyncLocalStorage } from "async_hooks";

export const db = drizzle(process.env.NILEDB_URL);
export const tenantContext = new AsyncLocalStorage<string | undefined>();

export function tenantDB<T>(cb: (tx: any) => T | Promise<T>): Promise<T> {
  return db.transaction(async (tx) => {
    const tenantId = tenantContext.getStore();
    console.log("executing query with tenant: " + tenantId);
    // if there's a tenant ID, set it in the transaction context
    if (tenantId) {
      await tx.execute(sql`set local nile.tenant_id = '${sql.raw(tenantId)}'`);
    }

    return cb(tx);
  }) as Promise<T>;
}
```

그런 다음 AsyncLocalStorage를 채우는 미들웨어를 설정하고, 요청을 처리할 때 `tenantDB` 메서드를 사용하세요:

```typescript copy filename="app.ts"
// Middleware to set tenant context
app.use("/api/tenants/:tenantId/*", async (c, next) => {
  const tenantId = c.req.param("tenantId");
  console.log("setting context to tenant: " + tenantId);
  return tenantContext.run(tenantId, () => next());
});

// Route handler
app.get("/api/tenants/:tenantId/todos", async (c) => {
    const todos = await tenantDB(c, async (tx) => {
      return await tx
        .select({
          id: todoSchema.id,
          tenant_id: todoSchema.tenantId,
          title: todoSchema.title,
          estimate: todoSchema.estimate,
        })
        .from(todoSchema);
    });
    return c.json(todos);
});
```
