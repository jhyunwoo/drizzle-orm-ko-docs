## 시작하기

이 가이드는 기본적인 **TypeORM** 프로젝트를 **Drizzle ORM**으로 마이그레이션하는 간단한 접근 방식을 제공합니다. 예시는 `PostgreSQL`에 초점을 맞추고 있지만, 과정은 다른 지원 데이터베이스에서도 비슷합니다.

### 마이그레이션 과정 개요

애플리케이션 유형이나 API 레이어와 관계없이, **TypeORM**에서 **Drizzle ORM**으로 전환하는 단계는 일관됩니다.

1. **Drizzle ORM**과 **Drizzle Kit** 설치
2. **Drizzle config** 파일 설정
3. 데이터베이스 introspect
4. 데이터베이스에 **Drizzle ORM** 연결
5. **TypeORM** 쿼리를 **Drizzle ORM** 쿼리로 전환

이 단계들은 Express, Koa, NestJS 같은 REST API를 개발할 때뿐 아니라, 데이터베이스 상호작용에 **TypeORM**을 사용하는 어떤 유형의 애플리케이션에도 적용할 수 있습니다.

## TypeORM 프로젝트 개요

이 가이드에서는 `Express`로 만든 REST API를 **Drizzle ORM**으로 마이그레이션하는 예제 프로젝트로 사용합니다. 이 프로젝트에는 네 개의 엔티티가 있습니다.

```typescript collapsable copy filename="src/entities/supplier.entity.ts"
import { Column, Entity, OneToMany, PrimaryGeneratedColumn } from 'typeorm';
import { Product } from './product.entity';

@Entity({ name: 'suppliers' })
export class Supplier {
  @PrimaryGeneratedColumn('increment')
  public id: number;

  @Column({ type: 'text' })
  public companyName: string;

  @Column({ type: 'text', nullable: true })
  public city: string;

  @Column({ type: 'text' })
  public country: string;

  @OneToMany(() => Product, (product) => product.supplier)
  public products: Product[];
}
```

```typescript collapsable copy filename="src/entities/product.entity.ts"
import { Column, Entity, JoinColumn, ManyToOne, OneToMany, PrimaryGeneratedColumn } from 'typeorm';
import { OrderDetail } from './order-detail.entity';
import { Supplier } from './supplier.entity';

@Entity({ name: 'products' })
export class Product {
  @PrimaryGeneratedColumn('increment')
  public id: number;

  @Column({ type: 'text' })
  public name: string;

  @Column({ type: 'integer' })
  public supplierId: number;

  @Column({ type: 'decimal', precision: 10, scale: 4 })
  public unitPrice: number;

  @Column({ type: 'integer' })
  public unitsInStock: number;

  @OneToMany(() => OrderDetail, (orderDetail) => orderDetail.product)
  public orderDetails: OrderDetail[];

  @ManyToOne(() => Supplier, (supplier) => supplier.products)
  @JoinColumn({ name: 'supplierId', referencedColumnName: 'id' })
  public supplier: Supplier;
}
```

```typescript collapsable copy filename="src/entities/order.entity.ts"
import { Column, Entity, OneToMany, PrimaryGeneratedColumn } from 'typeorm';
import { OrderDetail } from './order-detail.entity';

@Entity({ name: 'orders' })
export class Order {
  @PrimaryGeneratedColumn('increment')
  public id: number;

  @Column({ type: 'date' })
  public orderDate: Date;

  @Column({ type: 'date', nullable: true })
  public shippedDate: Date;

  @Column({ type: 'text' })
  public shipAddress: string;

  @Column({ type: 'text', nullable: true })
  public shipPostalCode: string;

  @Column({ type: 'text' })
  public shipCountry: string;

  @OneToMany(() => OrderDetail, (orderDetail) => orderDetail.order)
  public orderDetails: OrderDetail[];
}
```

```typescript collapsable copy filename="src/entities/order-detail.entity.ts"
import { Column, Entity, JoinColumn, ManyToOne, PrimaryColumn } from 'typeorm';
import { Order } from './order.entity';
import { Product } from './product.entity';

@Entity({ name: 'order_details' })
export class OrderDetail {
  @PrimaryColumn({ type: 'integer' })
  public orderId: number;

  @PrimaryColumn({ type: 'integer' })
  public productId: number;

  @Column({ type: 'integer' })
  public quantity: number;

  @ManyToOne(() => Order, (order) => order.orderDetails)
  @JoinColumn({ name: 'orderId', referencedColumnName: 'id' })
  public order: Order;

  @ManyToOne(() => Product, (product) => product.orderDetails)
  @JoinColumn({ name: 'productId', referencedColumnName: 'id' })
  public product: Product;
}
```

모델 간 관계는 다음과 같습니다.

1. `Supplier`와 `Product` 사이의 `one-to-many`
2. `Order`와 `Product` 사이의 `many-to-many`

`many-to-many` 관계를 위해 `order_details` 조인 테이블을 만들 것이므로, `Order`와 `Product` 엔티티는 `OrderDetail` 엔티티와 `one-to-many` 관계를 갖게 됩니다.

#### Drizzle config 파일 설정

**Drizzle config**는 **Drizzle Kit**에서 사용하는 설정 파일로, 데이터베이스 연결, migration 폴더, 스키마 파일에 관한 모든 정보를 담고 있습니다.

프로젝트 루트에 `drizzle.config.ts` 파일을 만들고 다음 내용을 추가하세요.

```typescript copy filename="drizzle.config.ts"
import 'dotenv/config'; // make sure to install dotenv package

export default defineConfig({
  dialect: 'postgresql',
  out: './src/drizzle',
  schema: './src/drizzle/schema.ts',
  dbCredentials: {
    host: process.env.DB_HOST!,
    port: Number(process.env.DB_PORT!),
    user: process.env.DB_USERNAME!,
    password: process.env.DB_PASSWORD!,
    database: process.env.DB_NAME!,

  // Print all statements

  // Always ask for confirmation

```

#### 데이터베이스 introspect

**Drizzle Kit**은 데이터베이스를 introspect하고 스키마 파일을 생성하는 CLI 명령을 제공합니다. 스키마 파일에는 데이터베이스 테이블, 컬럼, 관계, 인덱스에 대한 모든 정보가 들어 있습니다.

```bash
npx drizzle-kit introspect
```

##### select 쿼리 바꾸기

이 섹션에서는 단일 행 선택, 다중 행 선택, 행 개수 세기, 행 필터링, 테이블 join, 결과 페이지네이션 방법을 보여드리겠습니다.

1. `GET /products/:id`

**TypeORM**에서는 응답 타입이 엄격하게 지정되지 않습니다. 예를 들어 relation을 포함하거나 전체가 아니라 일부 필드만 선택하도록 바꿔도, 이런 변경이 응답 타입에 반영되지 않습니다.

```typescript copy filename="src/controllers/product.controller.ts"
import dataSource from '../db/typeorm.config';
import { Product } from '../entities/product.entity';

const { id } = req.params;

const repository = dataSource.getRepository(Product);

const response = await repostitory.findOne({
  where: { id },
  relations: ['supplier'],
});
```

**Drizzle ORM**에서는 쿼리를 다음과 같이 구현합니다.

```typescript copy filename="src/controllers/product.controller.ts"
import { eq } from 'drizzle-orm';
import { db } from '../drizzle/db';
import { products, suppliers } from '../drizzle/schema';

const { id } = req.params;

const response = await db
  .select({
    product: products,
    supplier: suppliers,
  })
  .from(products)
  .where(eq(products.id, id))
  .leftJoin(suppliers, eq(suppliers.id, products.supplierId));

// or you can use relational queries
const response = await db.query.products.findFirst({
  where: (products, { eq }) => eq(products.id, id),
  with: {
    supplier: true,
  },

```

**Drizzle ORM**에서는 응답 타입이 select 객체에 명시한 내용과 정확히 일치하므로, `supplier` relation을 포함하는 것도 완전히 type-safe합니다.

```typescript
// response type
const response: {
  product: {
    name: string;
    id: number;
    supplierId: number;
    unitPrice: string;
    unitsInStock: number;
  };
  supplier: {
    id: number;
    companyName: string;
    city: string | null;
    country: string;
  } | null;
}[]
```

3. `GET /orders/:id`

**TypeORM**에서는 `findOne` 메서드로 relation과 특정 필드를 함께 선택하면서 `aggregation functions`를 사용할 수 없습니다. 그래서 역시 type-safe하지 않은 `querybuilder`를 사용해야 합니다.

`orders` 테이블에서 `id`, `orderDate`, `shipCountry` 필드를 선택하고, `aggregation functions`를 사용해 주문의 `totalPrice`, 주문 내 상품의 `totalQuantity`, 주문 내 `totalProducts` 개수를 합산해서 가져오고 싶습니다.

```typescript copy filename="src/controllers/order.controller.ts"
import dataSource from '../db/typeorm.config';
import { Order } from '../entities/order.entity';

const { id } = req.params;

const orderRepository = dataSource.getRepository(Order);

const orderQueryBuilder = orderRepository.createQueryBuilder('order');

const response = await orderQueryBuilder
  .select([
    'order.id as id',
    'order.orderDate as "orderDate"',
    'order.shipCountry as "shipCountry"',
    'SUM(product.unitPrice * detail.quantity)::float as "totalPrice"',
    'SUM(detail.quantity)::int as "totalQuantity"',
    'COUNT(detail.productId)::int as "totalProducts"',
  ])
  .leftJoin('order.orderDetails', 'detail')
  .leftJoin('detail.product', 'product')
  .groupBy('order.id')
  .where('order.id = :id', { id })
  .getRawOne();
```

**Drizzle ORM**에서는 쿼리를 다음과 같이 구현합니다.

```typescript copy filename="src/controllers/order.controller.ts"
import { eq, sql } from 'drizzle-orm';
import { db } from '../drizzle/db';
import { orders, orderDetails, products } from '../drizzle/schema';

const { id } = req.params;

const response = await db
      .select({
        id: orders.id,
        shipCountry: orders.shipCountry,
        orderDate: orders.orderDate,
        totalPrice: sql<number>`cast(sum(${orderDetails.quantity} * ${products.unitPrice}) as float)`,
        totalQuantity: sql<number>`cast(sum(${orderDetails.quantity}) as int)`,
        totalProducts: sql<number>`cast(count(${orderDetails.productId}) as int)`,
      })
      .from(orders)
      .where(eq(orders.id, id))
      .groupBy(orders.id)
      .leftJoin(orderDetails, eq(orderDetails.orderId, orders.id))
      .leftJoin(products, eq(products.id, orderDetails.productId));
```

**Drizzle ORM**에서는 aggregation을 사용한 결과도 type-safe합니다.

```typescript
// response type
const response: {
  id: number;
  shipCountry: string;
  orderDate: string;
  totalPrice: number;
  totalQuantity: number;
  totalProducts: number;
}[]
```

**참고:** 현재 relational queries에서는 aggregation이 지원되지 않으므로 `core queries`를 사용해야 합니다.

##### delete 쿼리 바꾸기

이 섹션에서는 단일 행과 여러 행을 transaction으로 삭제하는 방법을 보여드리겠습니다.

1. `DELETE /orders/:id`

```typescript copy filename="src/controllers/order.controller.ts"
import dataSource from '../db/typeorm.config';
import { OrderDetail } from '../entities/order-detail.entity';
import { Order } from '../entities/order.entity';

const { id } = req.params;

const queryRunner = dataSource.createQueryRunner();

await queryRunner.connect();

await queryRunner.startTransaction();

try {
  await queryRunner.manager.delete(OrderDetail, { orderId: id });

  await queryRunner.manager.delete(Order, { id });

  await queryRunner.commitTransaction();
} catch (e) {
  await queryRunner.rollbackTransaction();

  console.error(e);
} finally {
  await queryRunner.release();
}
```

**Drizzle ORM**에서는 쿼리를 다음과 같이 구현합니다.

```typescript copy filename="src/controllers/order.controller.ts"
import { eq } from 'drizzle-orm';
import { db } from '../drizzle/db';
import { orderDetails, orders } from '../drizzle/schema';

const { id } = req.params;

try {
  await db.transaction(async (tx) => {
    await tx.delete(orderDetails).where(eq(orderDetails.orderId, id));

    await tx.delete(orders).where(eq(orders.id, id));
  });
} catch (e) {
  console.error(e);
}
```
