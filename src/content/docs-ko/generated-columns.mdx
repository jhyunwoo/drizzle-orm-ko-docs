# Generated Column

<Callout type="info">
이 기능을 사용하려면 `drizzle-orm@0.32.0` 이상과 `drizzle-kit@0.23.0` 이상이 필요합니다
</Callout>

1. Virtual(또는 비영속적) Generated Column: 이 column은 조회될 때마다 동적으로 계산됩니다. 데이터베이스 저장 공간을 차지하지 않습니다.

2. Stored(또는 영속적) Generated Column: 이 column은 row가 insert되거나 update될 때 계산되고 그 값이 데이터베이스에 저장됩니다. 따라서 index를 만들 수 있고, query마다 값을 다시 계산할 필요가 없으므로 query 성능을 향상시킬 수 있습니다.

<Callout type="info">
    생성된 column의 구현과 사용법은 SQL 데이터베이스마다 크게 다를 수 있습니다. PostgreSQL, MySQL, SQLite는 생성된 column과 관련해 각각 고유한 기능, 성능, 제약 사항을 가지고 있습니다. 이 섹션에서는 각 데이터베이스 시스템에서 생성된 column을 가장 잘 활용하는 방법을 이해할 수 있도록 이러한 차이를 자세히 살펴봅니다.
</Callout>

    #### 데이터베이스 측
    **Types**: `STORED` only

    **동작 방식**
    - insert 또는 update 중에 다른 column을 기준으로 값을 자동 계산합니다.

    **기능**
    - 복잡한 expression을 미리 계산하여 데이터 접근을 단순화합니다.
    - 생성된 column에 대한 index 지원으로 query 성능을 향상시킵니다.

    **제한 사항**
    - default 값을 지정할 수 없습니다.
    - expression은 다른 생성된 column을 참조하거나 subquery를 포함할 수 없습니다.
    - 생성된 column expression을 수정하려면 schema 변경이 필요합니다.
    - primary key, foreign key, unique constraint에 직접 사용할 수 없습니다.

    자세한 내용은 [PostgreSQL](https://www.postgresql.org/docs/current/ddl-generated-columns.html) 문서를 확인하세요

    #### Drizzle 측
    Drizzle에서는 어떤 column type이든 `.generatedAlwaysAs()` 함수를 지정하고 지원되는 sql query를 추가해,
    이 column 데이터를 생성하도록 할 수 있습니다.

    #### 기능
    이 함수는 생성 expression을 2가지 방식으로 받을 수 있습니다:

    <Callout type='warning' collapsed="1.0.0-beta.12 버전부터 변경된 내용">
    
    이전 버전에서는 `.generatedAlwaysAs()`가 literal도 expression으로 받았습니다.

    **`string`**
    <CodeTab>
    ```ts
    export const test = pgTable("test", {
        generatedName: text("gen_name").generatedAlwaysAs(`'hello world!'`),
    });
    ```
    ```sql
    CREATE TABLE "test" (
	    "gen_name" text GENERATED ALWAYS AS ('hello world!') STORED
    );
    ```
    </CodeTab>
    
    </Callout>

    **`sql`** tag - 일부 값을 drizzle이 대신 escape해 주길 원한다면

    <CodeTab>
    ```ts
    export const test = pgTable("test", {
        generatedName: text("gen_name").generatedAlwaysAs(sql`'hello "world"!'`),
    });
    ```
    ```sql
    CREATE TABLE "test" (
	    "gen_name" text GENERATED ALWAYS AS ('hello "world"!') STORED
    );
    ```
    </CodeTab>

    **`callback`** - 테이블의 column을 참조해야 한다면
    <CodeTab>
    ```ts
    export const test = pgTable("test", {
        name: text("first_name"),
        generatedName: text("gen_name").generatedAlwaysAs(
          (): SQL => sql`'hi, ' || ${test.name} || '!'`
        ),
    });
    ```
    ```sql
    CREATE TABLE "test" (
	    "first_name" text,
	    "gen_name" text GENERATED ALWAYS AS ('hi, ' || "test"."first_name" || '!') STORED
    );
    ```
    </CodeTab>

	```typescript copy {17-19}
    import { customType, index, integer, pgTable, text } from "drizzle-orm/pg-core";

      dataType() {
        return "tsvector";
    ```

    ```sql {4}
    	"content_search" "tsvector" GENERATED ALWAYS AS (to_tsvector('english', "test"."content")) STORED
    ```

    #### 데이터베이스 측
    **Types**: `STORED`, `VIRTUAL`

    **동작 방식**
    - 테이블 스키마에서 expression으로 정의됩니다.
    - Virtual column은 read 작업 중에 계산됩니다.
    - Stored column은 write 작업 중에 계산되어 저장됩니다.

    **기능**
    - SELECT, INSERT, UPDATE, DELETE statement에서 사용할 수 있습니다.
    - virtual과 stored 모두 index를 만들 수 있습니다.
    - NOT NULL 및 기타 constraint를 지정할 수 있습니다.
    
    **제한 사항**
    - 생성된 column에 값을 직접 insert하거나 update할 수 없습니다

    자세한 내용은 [MySQL Alter Generated](https://dev.mysql.com/doc/refman/8.4/en/alter-table-generated-columns.html) 문서와 [MySQL create generated](https://dev.mysql.com/doc/refman/8.4/en/create-table-generated-columns.html) 문서를 확인하세요

    #### 제한 사항
    Drizzle Kit의 `push` command에도 제한이 있습니다:
    1. `push`를 사용해 생성 constraint expression과 type을 바꿀 수 없습니다. Drizzle-kit은 이 변경을 무시합니다. 작동하게 하려면 `drop the column`을 하고, `push`한 뒤, `add a column with a new expression`을 해야 합니다. 이는 데이터베이스 측의 복잡한 매핑 때문인데, schema expression이 데이터베이스 측에서 수정되고 introspection 시에는 다른 string을 얻게 되기 때문입니다. 이 expression을 사용자가 바꾼 것인지, 아니면 데이터베이스가 바꾸고 formatting한 것인지 확실히 알 수 없습니다. 이 column들은 생성된 column이고 `push`는 주로 로컬 데이터베이스에서의 프로토타이핑에 쓰이므로, 생성된 column을 `drop`하고 `create`하는 작업은 빠르게 수행할 수 있습니다. 이 column들은 `generated`이므로 모든 데이터는 복원됩니다
    2. `generate`는 제한이 없어야 합니다

    ```sql
      `id` int,

      `name` text,
      `stored_gen` text GENERATED ALWAYS AS (concat(`users`.`name`, ' ', 'hello')) STORED,
      `virtual_gen` text GENERATED ALWAYS AS (concat(`users`.`name`, ' ', 'hello')) VIRTUAL
    ```

    #### 제한 사항
    Drizzle Kit의 `push` 및 `generate` command에도 제한이 있습니다:
    1. 기존 테이블에서 stored type과 함께 generated constraint expression을 변경할 수 없습니다. 이 경우 테이블을 삭제하고 다시 만들어야 합니다. 이는 SQLite가 이런 동작을 제한하기 때문입니다. 향후 릴리스에서 이 경우를 처리할 예정입니다(데이터 마이그레이션이 포함된 새 테이블 생성 방식이 됩니다).
    2. 위와 같은 이유로 기존 column에 `stored` 생성 expression을 추가할 수 없습니다. 하지만 기존 column에 `virtual` expression은 추가할 수 있습니다.
    3. 위와 같은 이유로 기존 column의 `stored` 생성 expression을 변경할 수 없습니다. 하지만 `virtual` expression은 변경할 수 있습니다.
    4. 위와 같은 이유로 generated constraint type을 `virtual`에서 `stored`로 변경할 수 없습니다. 하지만 `stored`에서 `virtual`로는 변경할 수 있습니다.

	```typescript copy
    export const users = sqliteTable("users", {
      id: int("id"),
      name: text("name"),
      storedGenerated: text("stored_gen").generatedAlwaysAs(
        (): SQL => sql`${users.name} || 'hello'`,
        { mode: "stored" }
      ),
      virtualGenerated: text("virtual_gen").generatedAlwaysAs(
        (): SQL => sql`${users.name} || 'hello'`,
        { mode: "virtual" }
      ),
    });
    ```
    ```sql
    CREATE TABLE `users` (
	    `id` integer,
	    `name` text,
	    `stored_gen` text GENERATED ALWAYS AS ("name" || 'hello') STORED,
	    `virtual_gen` text GENERATED ALWAYS AS ("name" || 'hello') VIRTUAL
    );
    ```
