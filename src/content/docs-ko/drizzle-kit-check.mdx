# `drizzle-kit check`

<Prerequisites>
- Drizzle 및 `drizzle-kit` 시작하기 - [여기를 읽으세요](/docs/get-started)
- Drizzle 스키마 기본 사항 - [여기 읽기](/docs/sql-schema-declaration)
- 데이터베이스 연결 기본 사항 - [여기를 읽어보세요](/docs/connect-overview)
- Drizzle 마이그레이션 기본 사항 - [여기에서 읽기](/docs/migrations)
- Drizzle Kit [개요](/docs/kit-overview) 및 [구성 파일](/docs/drizzle-config-file)
- `drizzle-kit generate` 명령 - [여기를 읽으세요](/docs/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit check` 명령을 사용하면 생성된 SQL 마이그레이션 기록의 일관성을 확인할 수 있습니다.

이는 여러 개발자가 프로젝트를 진행하고 있을 때 매우 유용합니다. 
다른 지점의 데이터베이스 스키마 변경 - [팀을 위한 마이그레이션](/docs/kit-migrations-for-teams)에 대해 자세히 알아보세요.

<br/>
<hr/>
<br/>

`drizzle-kit check` 명령을 사용하려면 `dialect` 및 데이터베이스 연결 자격 증명을 모두 지정해야 합니다. 
[drizzle.config.ts](/docs/drizzle-config-file) 구성 파일이나 CLI 옵션을 통해 제공할 수 있습니다.

<CodeTabs items={["구성 파일 포함", "CLI 옵션으로"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
});
```
```shell
npx drizzle-kit check
```
</Section>
```shell
npx drizzle-kit check --dialect=postgresql
```
</CodeTabs>

### 하나의 프로젝트에 여러 구성 파일
프로젝트에 여러 구성 파일이 있을 수 있습니다. 이는 동일한 프로젝트에 여러 데이터베이스 단계나 여러 데이터베이스가 있는 경우 매우 유용합니다.
<Npx>
  drizzle-kit check --config=drizzle-dev.config.ts
  drizzle-kit check --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 확장된 구성 목록
[drizzle.config.ts](/docs/drizzle-config-file) 파일을 통해 `drizzle-kit`을 구성하는 것이 좋습니다. 
하지만 필요한 경우 CLI를 통해 모든 구성 옵션을 제공할 수 있습니다. CI/CD 파이프라인 등
<rem025/>
|           |            |                                                                         |
| :--------- | :--------- | :--------------------------------------------------------- |
| `dialect` | `required` | 사용 중인 데이터베이스 방언입니다. `postgresql`, `mysql` 또는 `sqlite`일 수 있습니다 |
| `out` |            | 마이그레이션 폴더, 기본값=`./drizzle` |
| `config` |            | 구성 파일 경로, 기본값=`drizzle.config.ts` |
<br/>
<Npx>
drizzle-kit check --dialect=postgresql
drizzle-kit check --dialect=postgresql --out=./migrations-folder
</Npx>
