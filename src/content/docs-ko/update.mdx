# SQL Update

```typescript copy
await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'));
```

`update`에 전달하는 object는 데이터베이스 스키마의 column 이름과 일치하는 key를 가져야 합니다.
object 안에서 값이 `undefined`인 항목은 무시됩니다. column을 `null`로 설정하려면 `null`을 전달하세요.
다음과 같이 update object에서 사용할 값으로 SQL을 전달할 수도 있습니다:

```typescript copy
await db.update(users)
  .set({ updatedAt: sql`NOW()` })
  .where(eq(users.name, 'Dan'));
```

### Limit

<IsSupportedChipGroup chips={{ 'PostgreSQL': false, 'MySQL': true, 'SQLite': true, 'SingleStore': true, 'MSSQL': false, 'CockroachDB': false }} />

`.limit()`을 사용해 query에 `limit` clause를 추가할 수 있습니다. 예를 들면:
<Section>
```typescript
await db.update(usersTable).set({ verified: true }).limit(2);
```
```sql
update "users" set "verified" = $1 limit $2;
```
</Section>

### Order By
`.orderBy()`를 사용해 query에 `order by` clause를 추가하여 지정한 field로 결과를 정렬할 수 있습니다:
<Section>
```typescript
import { asc, desc } from 'drizzle-orm';

await db.update(usersTable).set({ verified: true }).orderBy(usersTable.name);
await db.update(usersTable).set({ verified: true }).orderBy(desc(usersTable.name));

// order by multiple fields
await db.update(usersTable).set({ verified: true }).orderBy(usersTable.name, usersTable.name2);
await db.update(usersTable).set({ verified: true }).orderBy(asc(usersTable.name), desc(usersTable.name2));
```
```sql
update "users" set "verified" = $1 order by "name";
update "users" set "verified" = $1 order by "name" desc;

update "users" set "verified" = $1 order by "name", "name2";
update "users" set "verified" = $1 order by "name" asc, "name2" desc;
```
</Section>

### Returning
<IsSupportedChipGroup chips={{ 'PostgreSQL': true, 'SQLite': true, 'MySQL': false , 'SingleStore': false, 'MSSQL': false, 'CockroachDB': true }} />
PostgreSQL과 SQLite에서는 row를 update하고 그 값을 다시 받을 수 있습니다:
```typescript copy
const updatedUserId: { updatedId: number }[] = await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'))
  .returning({ updatedId: users.id });
```

### Output
<IsSupportedChipGroup chips={{ 'MSSQL': true }} />
row를 update하고, update 전과 후의 row를 다시 받을 수 있습니다:

```typescript copy
type User = typeof users.$inferSelect;

const updatedUserId: User[] = await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'))
  .output();
```

update 후 일부 사용자 정보만 반환하려면:

```ts
const updatedUserId: { inserted: { updatedId: number }}[] = await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'))
  .output({ inserted: { updatedId: users.id }});
```

update 전에 데이터베이스에 있던 row를 반환하려면:

```ts
type User = typeof users.$inferSelect;

const updatedUserId: { deleted: User }[] = await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'))
  .output({ deleted: true });
```

row의 이전 버전과 새 버전을 모두 반환하려면:

```ts
type User = typeof users.$inferSelect;

const updatedUserId: { deleted: User, inserted: User }[] = await db.update(users)
  .set({ name: 'Mr. Dan' })
  .where(eq(users.name, 'Dan'))
  .output({ deleted: true, inserted: true });
```

## `with update` clause

<Callout>
  [select](/docs/select#with-clause), [insert](/docs/insert#with-insert-clause), [delete](/docs/delete#with-delete-clause)에서 WITH statement를 사용하는 방법을 확인하세요
</Callout>

`with` clause를 사용하면 common table expression (CTE)라고 불리는 더 작은 subquery로 나누어 복잡한 query를 단순화하는 데 도움이 됩니다:
<Section>
```typescript copy
const averagePrice = db.$with('average_price').as(
        db.select({ value: sql`avg(${products.price})`.as('value') }).from(products)
);

const result = await db.with(averagePrice)
		.update(products)
		.set({
			cheap: true
		})
		.where(lt(products.price, sql`(select * from ${averagePrice})`))
		.returning({
			id: products.id
		});
```
```sql
with "average_price" as (select avg("price") as "value" from "products") 
update "products" set "cheap" = $1 
where "products"."price" < (select * from "average_price") 
returning "id"
```
</Section>

## Update ... from

<IsSupportedChipGroup chips={{ 'PostgreSQL': true, 'MySQL': false, 'SQLite': true, 'SingleStore': false, 'MSSQL': false, 'CockroachDB': true }} />

SQLite 문서에서 언급하듯이:

> UPDATE-FROM은 UPDATE statement가 데이터베이스의 다른 테이블에 의해 구동되도록 허용하는 SQL의 확장입니다. 
"target" table은 update되는 대상 테이블 자체를 의미합니다. UPDATE-FROM을 사용하면
데이터베이스의 다른 테이블과 target table을 join하여 어떤 row를 update해야 하는지,
그리고 그 row의 새 값이 무엇이어야 하는지 계산하는 데 도움을 받을 수 있습니다

마찬가지로 PostgreSQL 문서에는 다음과 같이 나와 있습니다:

> WHERE 조건과 update expression에 다른 테이블의 column이 나타나도록 허용하는 table expression

Drizzle도 `drizzle-orm@0.36.3` 버전부터 이 기능을 지원합니다.

<Section>
```ts
await db
  .update(users)
  .set({ cityId: cities.id })
  .from(cities)
  .where(and(eq(cities.name, 'Seattle'), eq(users.name, 'John')))
```
```sql
update "users" set "city_id" = "cities"."id" 
from "cities" 
where ("cities"."name" = $1 and "users"."name" = $2)

-- params: [ 'Seattle', 'John' ]
```
</Section>

join된 테이블에 alias를 붙일 수도 있습니다(PG에서는 update 대상 테이블에도 alias를 붙일 수 있습니다).
<Section>
```ts
const c = alias(cities, 'c');
await db
  .update(users)
  .set({ cityId: c.id })
  .from(c);
```
```sql
update "users" set "city_id" = "c"."id" 
from "cities" "c"
```
</Section>

<IsSupportedChipGroup chips={{ 'PostgreSQL': true, 'MySQL': false, 'SQLite': false, 'SingleStore': false, 'MSSQL': false, 'CockroachDB': true }} />

Postgres에서는 join된 테이블의 column도 반환할 수 있습니다.
<Section>
```ts
const updatedUsers = await db
  .update(users)
  .set({ cityId: cities.id })
  .from(cities)
  .returning({ id: users.id, cityName: cities.name });
```
```sql
update "users" set "city_id" = "cities"."id" 
from "cities" 
returning "users"."id", "cities"."name"
```
</Section>
