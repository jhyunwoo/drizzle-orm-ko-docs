### int
부호 있는 4바이트 정수입니다.     

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	int: int()
});

```

```sql
CREATE TABLE [table] (
	[int] int
);
```
</Section>

<Section>
```typescript
import { sql } from "drizzle-orm";
import { int, mssqlTable } from "drizzle-orm/mssql-core";

export const table = pgTable('table', {
	int1: int().default(10),
});

```

```sql
CREATE TABLE [table] (
	[int1] int DEFAULT 10
);
```
</Section>

### bigint
`bigint`

부호 있는 8바이트 정수입니다.  

2^31보다 크고 2^53보다 작은 값을 예상한다면 `mode: 'number'`를 활용해 bigint 대신 javascript number로 다룰 수 있습니다.
<Section>
```typescript
import { bigint, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	bigint: bigint({ mode: 'number' })
});

// will be inferred as `number`
bigint: bigint({ mode: 'number' })

// will be inferred as `bigint`
bigint: bigint({ mode: 'bigint' })

// will be inferred as `string`
bigint: bigint({ mode: 'string' })
```

```sql
CREATE TABLE [table] (
	[bigint] bigint
);
```
</Section>

<Section>
```typescript
import { sql } from "drizzle-orm";
import { bigint, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	bigint1: bigint({ mode: 'number' }).default(10)
});
```


### text
`text`  
서버의 코드 페이지에 따른 가변 길이 비유니코드 데이터이며, 최대 문자열 길이는 2^31 - 1 (2,147,483,647)입니다.

자세한 내용은 공식 MSSQL **[docs.](https://learn.microsoft.com/en-us/sql/t-sql/data-types/ntext-text-and-image-transact-sql?view=sql-server-ver17#text)**를 참고하세요.
  
`{ enum: ["value1", "value2"] }` 설정을 정의해 `insert` 및 `select` 타입을 추론할 수 있지만, 런타임 값은 검사하지 **않습니다**.
<Section>
```typescript
import { text, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
  text: text()
});

// will be inferred as text: "value1" | "value2" | null
text: text({ enum: ["value1", "value2"] })
```

```sql
CREATE TABLE [table] (
	[text] text
);
```
</Section>

### varchar
`varchar(n|max)`  
가변 크기 문자열 데이터입니다. n을 사용해 문자열 크기를 바이트 단위로 정의하며, 값은 1부터 8,000까지 지정할 수 있습니다.

자세한 내용은 공식 MSSQL **[docs.](https://learn.microsoft.com/en-us/sql/t-sql/data-types/char-and-varchar-transact-sql?view=sql-server-ver17#varchar---n--max--)**를 참고하세요.

`{ enum: ["value1", "value2"] }` 설정을 정의해 `insert` 및 `select` 타입을 추론할 수 있지만, 런타임 값은 검사하지 **않습니다**.

`length` 매개변수는 MSSQL 문서에 따르면 선택 사항입니다.
<Section>
```typescript
import { varchar, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
  varchar1: varchar(),
  varchar2: varchar({ length: 256 }),
  varchar3: varchar({ length: 'max' })
});

// will be inferred as text: "value1" | "value2" | null
varchar: varchar({ enum: ["value1", "value2"] }),
```

```sql
CREATE TABLE [table] (
	[varchar1] varchar,
	[varchar2] varchar(256),
	[varchar3] varchar(max)
);
```
</Section>

자세한 내용은 공식 MSSQL **[docs.](https://learn.microsoft.com/en-us/sql/t-sql/data-types/nchar-and-nvarchar-transact-sql?view=sql-server-ver17#nvarchar---n--max--)**를 참고하세요.

```sql
);
```

### datetime
`datetime`  

24시간제를 기반으로 한 시간과 소수 초를 포함하는 날짜를 정의합니다.

<Callout title='MSSQL docs'>
새로운 작업에서는 datetime 사용을 피하세요. 대신 time, date, datetime2, datetimeoffset 데이터 타입을 사용하세요. 이 타입들은 SQL 표준과 일치하며 더 이식성이 높습니다. time, datetime2, datetimeoffset은 더 높은 초 정밀도를 제공합니다. datetimeoffset은 전 세계에 배포되는 애플리케이션을 위한 시간대 지원을 제공합니다.
</Callout>

자세한 내용은 공식 MSSQL **[docs.](https://learn.microsoft.com/en-us/sql/t-sql/data-types/datetime-transact-sql?view=sql-server-ver17#description)**를 참고하세요.
<Section>
```typescript
import { datetime, mssqlTable } from "drizzle-orm/mssql-core";

const table = mssqlTable('table', {
	datetime: datetime(),
});
```

```sql
CREATE TABLE [table] (
	[datetime] datetime
);
```
</Section>
`date` 또는 `string` 추론 모드를 지정할 수 있습니다.
```typescript
// will infer as date
datetime: datetime({ mode: "date" }),

// will infer as string
datetime: datetime({ mode: "string" }),
```

자세한 내용은 공식 MSSQL **[docs.](https://learn.microsoft.com/en-us/sql/t-sql/data-types/datetime2-transact-sql?view=sql-server-ver17#datetime2-description)**를 참고하세요.

```typescript
	datetime2: datetime2(),

```


자세한 내용은 공식 MSSQL **[docs.](https://learn.microsoft.com/en-us/sql/t-sql/data-types/datetimeoffset-transact-sql?view=sql-server-ver17#datetimeoffset-description)**를 참고하세요.

### 데이터 유형 사용자 지정
모든 컬럼 빌더에는 컬럼의 데이터 타입을 사용자 지정할 수 있는 `.$type()` 메서드가 있습니다. 

예를 들어 알 수 없는 타입이나 브랜드 타입과 함께 사용할 때 유용합니다.
```ts
type UserId = number & { __brand: 'user_id' };
type Data = {
	foo: string;
	bar: number;
};

const users = mssqlTable('users', {
  id: int().$type<UserId>().primaryKey(),
  jsonField: json().$type<Data>(),
});
```

### 기본값
`DEFAULT` 절은 `INSERT`를 수행할 때 사용자가 명시적으로 값을 제공하지 않은 경우, 해당 컬럼에 사용할 기본값을 지정합니다.
컬럼 정의에 명시적인 `DEFAULT` 절이 붙어 있지 않다면,
그 컬럼의 기본값은 `NULL`입니다.

명시적인 `DEFAULT` 절은 기본값으로 `NULL`,
문자열 상수, blob 상수, 부호 있는 숫자, 혹은 괄호로 둘러싼 상수 표현식을 지정할 수 있습니다.

<Section>
```typescript
import { sql } from "drizzle-orm";
import { int, mssqlTable, text } from "drizzle-orm/mssql-core";

const table = mssqlTable('table', {
	integer: integer().default(42),
	text: text().default('text'),
});
```

```sql
CREATE TABLE [table] (
	[integer1] integer DEFAULT 42,
	[text] text DEFAULT 'text',
);
```
</Section>

같은 함수의 다른 별칭인 `$default()` 또는 `$defaultFn()`을 사용하면, 
런타임에 기본값을 생성하고 모든 insert 쿼리에서 이 값을 사용할 수 있습니다. 

<Callout type="info" emoji="ℹ️">
	참고: 이 값은 `drizzle-kit` 동작에 영향을 주지 않으며, `drizzle-orm` 런타임에서만 사용됩니다.
</Callout>

```ts
import { text, mssqlTable } from "drizzle-orm/mssql-core";
import { createId } from '@paralleldrive/cuid2';

const table = mssqlTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

같은 함수의 다른 별칭인 `$onUpdate()` 또는 `$onUpdateFn()`을 사용하면, 
런타임에 기본값을 생성하고 모든 update 쿼리에서 이 값을 사용할 수 있습니다. 

컬럼에 동적인 업데이트 값을 추가합니다. 행이 업데이트되면 함수가 호출되며, 
값이 따로 제공되지 않은 경우 반환값이 컬럼 값으로 사용됩니다.
기본값(또는 `$defaultFn`)이 제공되지 않았다면 함수는
행이 삽입될 때에도 호출되고, 반환된 값이 컬럼 값으로 사용됩니다.

<Callout type="info" emoji="ℹ️">
	참고: 이 값은 `drizzle-kit` 동작에 영향을 주지 않으며, `drizzle-orm` 런타임에서만 사용됩니다.
</Callout>

```ts
import { int, datetime2, text, mssqlTable } from "drizzle-orm/mssql-core";

const table = mssqlTable('table', {
	updateCounter: int().default(sql`1`).$onUpdateFn((): SQL => sql`${table.updateCounter} + 1`),
	updatedAt: datetime2({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```


### null 아님
`NOT NULL` 제약 조건은 해당 컬럼에 `NULL` 값이 들어갈 수 없음을 의미합니다.

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

const table = mssqlTable('table', {
	int: int().notNull(),
});
```

```sql
CREATE TABLE [table] (
	[int] int NOT NULL
);
```
</Section>


### 기본 키
기본 키 제약 조건은 하나의 컬럼 또는 컬럼 그룹이 테이블의 행을 고유하게 식별하는 데 사용될 수 있음을 나타냅니다. 
즉, 값이 고유해야 하고 null이 아니어야 합니다.
<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

const table = pgTable('table', {
	id: int().primaryKey(),
});
```

```sql
CREATE TABLE [table] (
	[id] int PRIMARY KEY
);
```
</Section>
