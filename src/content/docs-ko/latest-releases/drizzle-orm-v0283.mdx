## 수정 사항

- 결과가 비어 있을 때 sqlite-proxy와 SQL.js의 `.get()` 응답을 수정했습니다

## 새 기능

### 🎉 SQLite 간소화 쿼리 API 추가

### 🎉 column builders에 `.$defaultFn()` / `.$default()` 메서드 추가

자세한 내용은 [PostgreSQL](/docs/column-types/pg#default-value), [MySQL](/docs/column-types/mysql#default-value), [SQLite](/docs/column-types/sqlite#default-value) 문서를 확인하세요.

런타임 기본값을 위해 `cuid()` 같은 함수에 어떤 로직이든, 어떤 구현이든 지정할 수 있습니다. Drizzle은 추가할 수 있는 구현 개수를 제한하지 않습니다.

> 참고: 이 값은 `drizzle-kit` 동작에 영향을 주지 않으며, `drizzle-orm`의 런타임에서만 사용됩니다

```ts copy {5}
import { varchar, mysqlTable } from "drizzle-orm/mysql-core";
import { createId } from '@paralleldrive/cuid2';

const table = mysqlTable('table', {
	id: varchar('id', { length: 128 }).$defaultFn(() => createId()),
});
```

### 🎉 더 편리한 table model type inference를 위해 `table.$inferSelect` / `table._.inferSelect`와 `table.$inferInsert` / `table._.inferInsert` 추가

- 🛠 더 명시적인 `InferSelectModel`과 `InferInsertModel`을 위해 `InferModel` 타입을 deprecated 처리했습니다

```ts copy {11,12,14,15}
import { InferSelectModel, InferInsertModel } from 'drizzle-orm'

const usersTable = pgTable('users', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  verified: boolean('verified').notNull().default(false),
  jsonb: jsonb('jsonb').$type<string[]>(),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
});

type SelectUser = typeof usersTable.$inferSelect;
type InsertUser = typeof usersTable.$inferInsert;

type SelectUser2 = InferSelectModel<typeof usersTable>;
type InsertUser2 = InferInsertModel<typeof usersTable>;
```

- 🛠 `.d.ts` 파일 번들링을 비활성화했습니다
