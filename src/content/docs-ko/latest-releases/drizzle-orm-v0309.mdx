## 새 기능

- SQLite에서 `.onConflictDoUpdate()` 설정에 단일 `where` 필드 대신 `setWhere`와 `targetWhere` 필드를 추가했습니다:

```ts copy
await db.insert(employees)
  .values({ employeeId: 123, name: 'John Doe' })
  .onConflictDoUpdate({
    target: employees.employeeId,
    targetWhere: sql`name <> 'John Doe'`,
    set: { name: sql`excluded.name` }
  });
  
await db.insert(employees)
  .values({ employeeId: 123, name: 'John Doe' })
  .onConflictDoUpdate({
    target: employees.employeeId,
    set: { name: 'John Doe' },
    setWhere: sql`name <> 'John Doe'`
  });
```

`.onConflictDoUpdate()` 메서드는 [here](/docs/insert#on-conflict-do-update)에서 더 알아보세요.

- 🛠️ `db._.fullSchema`를 통해 Drizzle 인스턴스에 schema 정보를 추가했습니다

## 수정 사항

- AWS Data API의 migrator를 수정했습니다

Drizzle과 AWS Data API 시작하기는 [documentation](/docs/get-started-postgresql#aws-data-api)를 참고하세요.
