## 새 기능

### 🎉 OP-SQLite 드라이버 지원

사용 예시

```ts copy {4,5,6,8}
import { open } from '@op-engineering/op-sqlite';
import { drizzle } from 'drizzle-orm/op-sqlite';

const opsqlite = open({
	name: 'myDB',
});

const db = drizzle(opsqlite);

await db.select().from(users);
```

더 많은 사용법과 설정 세부 내용은 [op-sqlite docs](http://orm.drizzle.team/docs/get-started-sqlite#op-sqlite)를 확인해 주세요.

## 수정 사항

- Expo 드라이버용 migration hook을 수정했습니다
