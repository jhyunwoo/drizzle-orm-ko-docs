## 새 기능

### 🎉 WITH UPDATE, WITH DELETE, WITH INSERT

이제 [INSERT](/docs/insert#with-insert-clause), [UPDATE](/docs/update#with-update-clause), [DELETE](/docs/delete#with-delete-clause) 구문과 함께 `WITH` 문을 사용할 수 있습니다.

사용 예시

<Section>
```ts copy {6,7}
const averageAmount = db.$with('average_amount').as(
	db.select({ value: sql`avg(${orders.amount})`.as('value') }).from(orders),
);

const result = await db
	.with(averageAmount)
	.delete(orders)
	.where(gt(orders.amount, sql`(select * from ${averageAmount})`))
	.returning({
		id: orders.id,
	});
```

```sql
with "average_amount" as (select avg("amount") as "value" from "orders") 
delete from "orders" 
where "orders"."amount" > (select * from "average_amount") 
returning "id";
```
</Section>

모든 구문에 대한 더 많은 예시는 다음 문서를 확인하세요:

### 🎉 migrations 테이블에 custom schema와 custom name 지정 가능

- **migrations용 custom table**

기본적으로 실행된 migration에 대한 모든 정보는 데이터베이스의 `__drizzle_migrations` 테이블에 저장되며, PostgreSQL의 경우 `drizzle` 스키마 안에 저장됩니다. 하지만 이 레코드를 어디에 저장할지 설정할 수 있습니다.

데이터베이스 안에 저장되는 migration용 custom table 이름을 추가하려면 `migrationsTable` 옵션을 사용해야 합니다.

사용 예시

```ts copy {3}
await migrate(db, {
	migrationsFolder: './drizzle',
	migrationsTable: 'my_migrations',
});
```

- **migrations용 custom schema**

> PostgreSQL 데이터베이스에서만 동작합니다

데이터베이스 안에 저장되는 migration용 custom schema 이름을 추가하려면 `migrationsSchema` 옵션을 사용해야 합니다.

사용 예시

```ts copy {3}
await migrate(db, {
	migrationsFolder: './drizzle',
	migrationsSchema: 'custom',
});
```

### 🎉 SQLite Proxy batch 및 Relational Queries 지원

SQLite proxy에 대한 자세한 내용은 [docs](/docs/get-started-sqlite#http-proxy)에서 확인할 수 있습니다.

- 이제 sqlite proxy 드라이버에서 `.query.findFirst`와 `.query.findMany` 문법을 사용할 수 있습니다

- SQLite Proxy는 다른 모든 드라이버와 마찬가지로 batch 요청을 지원합니다. 전체 [docs](/docs/batch-api)를 확인해 주세요

  batch 쿼리를 위한 별도의 callback을 지정하고, proxy server로 가는 요청을 처리해야 합니다:

```ts
import { drizzle } from 'drizzle-orm/sqlite-proxy';

type ResponseType = { rows: any[][] | any[] }[];

const db = drizzle(
	async (sql, params, method) => {
		// single query logic
	},
	// new batch callback
	async (
		queries: {
			sql: string;
			params: any[];
			method: 'all' | 'run' | 'get' | 'values';
		}[],
	) => {
		try {
			const result: ResponseType = await axios.post(
				'http://localhost:3000/batch',
				{ queries },
			);

			return result;
		} catch (e: any) {
			console.error('Error from sqlite proxy server:', e);
			throw e;
		}
	},
);
```

그리고 `db.batch([])` 메서드를 사용할 수 있으며, 이 메서드는 모든 쿼리를 proxy합니다.

> batch 응답은 proxy server로 보낸 순서와 동일한 순서를 가진 raw 값 배열(배열 안의 배열)이어야 합니다
