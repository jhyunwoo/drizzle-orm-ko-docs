## 🎉 PostgreSQL, MySQL, SQLite에서 `UNIQUE` constraints 지원 추가

PostgreSQL에서는 단일 컬럼 제약 조건의 경우 컬럼 수준에서 unique constraints를 정의할 수 있고, 다중 컬럼 제약 조건의 경우 세 번째 매개변수에서 정의할 수 있습니다. 두 경우 모두 constraint에 대한 커스텀 이름을 지정할 수 있습니다. 또한 PostgreSQL에는 테이블에서 둘 이상의 NULL 값을 허용하지 않도록 제한하는 `NULLS NOT DISTINCT` 옵션도 추가됩니다. [Reference](https://www.postgresql.org/docs/current/ddl-constraints.html#DDL-CONSTRAINTS-UNIQUE-CONSTRAINTS)

아래 예시는 서로 다른 `unique` 사용 방식을 보여 주기 위한 것뿐입니다. 이 테이블들의 실제 사용 사례를 찾지는 마세요.

```ts copy
// single column
const table = pgTable('table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull().unique(),
  state: char('state', { length: 2 }).unique('custom'),
  field: char('field', { length: 2 }).unique('custom_field', { nulls: 'not distinct' }),
});
// multiple columns
const table = pgTable('table', {
  id: serial('id').primaryKey(),
  name: text('name').notNull(),
  state: char('state', { length: 2 }),
}, (t) => ({
  first: unique('custom_name').on(t.name, t.state).nullsNotDistinct(),
  second: unique('custom_name1').on(t.name, t.state),
}));
```

MySQL에서는 `NULLS NOT DISTINCT` 옵션을 제외하면 동일하게 동작합니다. MySQL은 이 옵션을 지원하지 않는 것으로 보입니다.

아래 예시는 서로 다른 `unique` 사용 방식을 보여 주기 위한 것뿐입니다. 이 테이블들의 실제 사용 사례를 찾지는 마세요.

```ts copy
// single column
const table = mysqlTable('table', {
    id: serial('id').primaryKey(),
    name: text('name').notNull().unique(),
    state: text('state').unique('custom'),
    field: text('field').unique('custom_field'),
});
// multiple columns
const table = mysqlTable('cities1', {
    id: serial('id').primaryKey(),
    name: text('name').notNull(),
    state: text('state'),
}, (t) => ({
    first: unique().on(t.name, t.state),
    second: unique('custom_name1').on(t.name, t.state),
}));
```

SQLite에서는 unique constraints가 unique indexes와 동일합니다. SQLite에서 unique index에 이름을 지정할 수 있는 한, 내부 구현에서는 모든 unique constraints를 unique indexes로 취급합니다.

```ts copy
// single column
const table = sqliteTable('table', {
    id: int('id').primaryKey(),
    name: text('name').notNull().unique(),
    state: text('state').unique('custom'),
    field: text('field').unique(),
});
// multiple columns
const table = sqliteTable('table', {
    id: int('id').primaryKey(),
    name: text('name').notNull(),
    state: text('state'),
}, (t) => ({
    first: unique().on(t.name, t.state),
    second: unique('custom').on(t.name, t.state),
}));
```
