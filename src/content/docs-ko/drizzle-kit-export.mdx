# `drizzle-kit export` 

<Prerequisites>
- Drizzle 및 `drizzle-kit` 시작하기 - [여기를 읽으세요](/docs/get-started)
- Drizzle 스키마 기본 사항 - [여기 읽기](/docs/sql-schema-declaration)
- 데이터베이스 연결 기본 사항 - [여기를 읽어보세요](/docs/connect-overview)
- Drizzle 마이그레이션 기본 사항 - [여기에서 읽기](/docs/migrations)
- Drizzle Kit [개요](/docs/kit-overview) 및 [구성 파일](/docs/drizzle-config-file)
</Prerequisites>


<br/>

`drizzle-kit export`을 사용하면 Drizzle 스키마의 SQL 표현을 내보내고 콘솔 SQL DDL 표현을 인쇄할 수 있습니다.
<Callout collapsed="내부적으로는 어떻게 작동하나요?">
Drizzle Kit `export` 명령은 일련의 이벤트를 트리거합니다.
1. Drizzle 스키마 파일을 읽고 스키마의 json 스냅샷을 구성합니다.
3. json 차이점을 기반으로 SQL DDL 문을 생성합니다.
4. SQL DDL 문을 콘솔에 출력
</Callout>

Drizzle 마이그레이션 관리에 대한 [코드베이스 우선](/docs/migrations) 접근 방식을 다루도록 설계되었습니다. 
Drizzle 스키마의 SQL 표현을 내보내 Atlas와 같은 외부 도구가 모든 마이그레이션을 처리하도록 할 수 있습니다.

`drizzle-kit export` 명령을 사용하려면 `dialect` 및 `schema` 경로 옵션을 모두 제공해야 합니다. 
[drizzle.config.ts](/docs/drizzle-config-file) 구성 파일이나 CLI 옵션을 통해 설정할 수 있습니다.
<CodeTabs items={["구성 파일 포함", "CLI 옵션으로"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
});
```
```shell
npx drizzle-kit export
```
</Section>

```shell
npx drizzle-kit export --dialect=postgresql --schema=./src/schema.ts
```
</CodeTabs>

### 스키마 파일 경로
단일 `schema.ts` 파일을 보유하거나 프로젝트 전체에 원하는 만큼의 스키마 파일을 분산시킬 수 있습니다. 
Drizzle Kit에서는 `schema` 구성 옵션을 통해 경로를 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs)으로 지정해야 합니다.

<SchemaFilePaths/>
### 하나의 프로젝트에 여러 구성 파일
프로젝트에 여러 구성 파일이 있을 수 있습니다. 이는 동일한 프로젝트에 여러 데이터베이스 단계, 여러 데이터베이스 또는 서로 다른 데이터베이스가 있는 경우 매우 유용합니다.
<Npx>
  drizzle-kit export --config=drizzle-dev.config.ts
  drizzle-kit export --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 사용 가능한 구성의 확장 목록
`drizzle-kit export`에는 cli 전용 옵션 목록이 있습니다.

<rem025/>

|               |                                                      |
| :--------- | :-------------------------------------- |
| `--sql` | Drizzle 스키마의 SQL 표현 생성 |

기본적으로 Drizzle Kit는 SQL 파일을 출력하지만 앞으로는 다른 형식도 지원하려고 합니다.

<rem025/>

<Npx>
drizzle-kit push --name=init
drizzle-kit push --name=seed_users --custom
</Npx>

[drizzle.config.ts](/docs/drizzle-config-file) 파일을 통해 `drizzle-kit`을 구성하는 것이 좋습니다. 
하지만 필요한 경우 CLI를 통해 모든 구성 옵션을 제공할 수 있습니다. CI/CD 파이프라인 등

|               |            |                                                                            |
| :------------ | :------- | :--------------------------------------------------------- |
| `dialect` | `required` | <Dialects/> 중 하나인 데이터베이스 방언 |
| `schema` | `required` | 여러 스키마 파일이 있는 TypeScript 스키마 파일 또는 폴더의 경로 |
| `config` |            | 구성 파일 경로, 기본값은 `drizzle.config.ts` |
### 예
`./src/schema.ts`에 있는 Drizzle 스키마를 사용하여 Drizzle 스키마를 콘솔로 내보내는 방법의 예

또한 `configs` 폴더에 drizzle 구성 파일을 배치합니다.

구성 파일을 만들어 보겠습니다.
```plaintext {4}
📦 <project root>
 ├ 📂 configs
 │ └ 📜 drizzle.config.ts
 ├ 📂 src
 │ └ 📜 schema.ts
 └ …
```
```ts filename='drizzle.config.ts'
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
});
```

```ts filename='schema.ts'
import { pgTable, serial, text } from 'drizzle-orm/pg-core'

export const users = pgTable('users', {
	id: serial('id').primaryKey(),
	email: text('email').notNull(),
	name: text('name')
});
```
이제 달리자
```shell
npx drizzle-kit export --config=./configs/drizzle.config.ts
```
그리고 이슬비 스키마의 SQL 표현을 성공적으로 출력합니다.
```bash
CREATE TABLE "users" (
        "id" serial PRIMARY KEY NOT NULL,
        "email" text NOT NULL,
        "name" text
);
```
