# Drizzle \<\> React Native SQLite
React Native 앱에서 Drizzle ORM을 실행하려면 [`Expo SQLite`](#expo-sqlite)를 사용해 주세요.
저희가 확인한 유일한 [대중적인 라이브러리](https://github.com/andpor/react-native-sqlite-storage)는 이제 React Native와 Expo의 기본 런타임인 새로운 Hermes JavaScript 런타임을 지원하지 않습니다.
