# Drizzle Kit으로 마이그레이션하기
<Prerequisites>
- Drizzle과 `drizzle-kit` 시작하기 - [여기서 읽기](/docs/get-started)
- Drizzle 스키마 기초 - [여기서 읽기](/docs/sql-schema-declaration)
- 데이터베이스 연결 기초 - [여기서 읽기](/docs/connect-overview)
- Drizzle 마이그레이션 기초 - [여기서 읽기](/docs/migrations)
- Drizzle Kit [개요](/docs/kit-overview) 및 [config 파일](/docs/drizzle-config-file)
- `drizzle-kit generate` 명령 - [여기서 읽기](/docs/drizzle-kit-generate)
- `drizzle-kit migrate` 명령 - [여기서 읽기](/docs/drizzle-kit-migrate)
</Prerequisites>

Drizzle을 사용하면 현재 Drizzle Kit이 지원하지 않는 DDL 변경이나 데이터 시딩을 위해, 직접 custom SQL 마이그레이션을 작성할 수 있는 빈 마이그레이션 파일을 생성할 수 있습니다. 그런 다음 [`drizzle-kit migrate`](/docs/drizzle-kit-migrate) 명령으로 실행할 수 있습니다.

```shell
drizzle-kit generate --custom --name=seed-users
```
