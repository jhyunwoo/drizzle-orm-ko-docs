# Drizzle Kit과 함께하는 Migrations
<Prerequisites>
- Drizzle과 `drizzle-kit` 시작하기 - [여기서 읽기](/docs/get-started)
- Drizzle schema 기초 - [여기서 읽기](/docs/sql-schema-declaration)
- 데이터베이스 연결 기초 - [여기서 읽기](/docs/connect-overview)
- Drizzle migrations 기초 - [여기서 읽기](/docs/migrations)
</Prerequisites>


**Drizzle Kit**은 Drizzle과 함께 SQL 데이터베이스 migration을 관리하기 위한 CLI 도구입니다.
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
먼저 Drizzle [get started](/docs/get-started)와 [migration fundamentals](/docs/migrations)를 살펴보고, 비즈니스 요구에 가장 잘 맞는 SQL migration 흐름을 선택하세요. 
</Callout>

Drizzle Kit은 schema를 기반으로 SQL migration 파일을 생성하고 실행하며, schema를 데이터베이스에 직접 push하고, 데이터베이스에서 schema를 pull하며, drizzle studio를 띄우고, 그 외 몇 가지 유틸리티 명령도 제공합니다.
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/drizzle-kit-generate) | 선언 시점 또는 이후 변경 사항을 기준으로 Drizzle schema에 맞는 SQL migration 파일을 생성합니다. [여기 보기](/docs/drizzle-kit-generate).       |
| [`drizzle-kit migrate`](/docs/drizzle-kit-migrate)   | 생성된 SQL migration 파일을 데이터베이스에 적용합니다. [여기 보기](/docs/drizzle-kit-migrate).                                                              |
| [`drizzle-kit pull`](/docs/drizzle-kit-pull)         | 데이터베이스 schema를 pull(introspect)하여 Drizzle schema로 변환한 뒤 코드베이스에 저장합니다. [여기 보기](/docs/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/drizzle-kit-push)         | 선언 시점 또는 이후 schema 변경 사항을 데이터베이스에 push합니다. [여기 보기](/docs/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/drizzle-kit-studio)     | 데이터베이스에 연결하고 Drizzle Studio용 프록시 서버를 띄워 편리하게 데이터베이스를 탐색할 수 있게 합니다. [여기 보기](/docs/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/drizzle-kit-check)       | 생성된 모든 migration을 순회하며 race condition(충돌)이 있는지 검사합니다. [여기 보기](/docs/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/drizzle-kit-up)             | 이전에 생성된 migration의 snapshot을 업그레이드할 때 사용합니다. [여기 보기](/docs/drizzle-kit-up)                                                                     |
<br/>

Drizzle Kit은 [drizzle.config.ts](/docs/drizzle-config-file) 설정 파일이나 CLI 파라미터를 통해 구성합니다.<br/>
최소한 SQL `dialect`와 `schema` 경로는 제공해야 Drizzle Kit이 migration을 어떻게 생성할지 알 수 있습니다.
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle config file
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["simple config", "extended config"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "postgresql",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "postgresql",
  schema: "./src/schema.ts",

  driver: "pglite",
  dbCredentials: {
    url: "./database/",
  },

  extensionsFilters: ["postgis"],
  schemaFilter: "public",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    prefix: "timestamp",
    table: "__drizzle_migrations__",
    schema: "public",
  },

  breakpoints: true,
  strict: true,
  verbose: true,
});
```
</CodeTabs>

CLI 파라미터를 통해 Drizzle Kit 설정 경로를 제공할 수도 있습니다. 여러 데이터베이스 stage가 있거나, 여러 데이터베이스를 쓰거나, 같은 프로젝트 안에서 서로 다른 데이터베이스를 다룰 때 매우 유용합니다.

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
